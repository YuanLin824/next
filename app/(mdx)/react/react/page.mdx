## 第一阶段：JSX 与组件（入门）

### 1. JSX — 在 JS 中写 HTML

```tsx

// 嵌入表达式 — 花括号内可以放任何 JS 表达式

}

// 属性 — 驼峰命名 className / onClick / htmlFor

```

### 2. 函数组件（推荐）

```tsx
// React 组件 = 返回 JSX 的纯函数
function Welcome({ name }: { name: string }) {
  return <h1>Hello, {name}!</h1>
}

function App() {
  return (
    <div>
      <Welcome name="React" />
    </div>
  )

```

### 3. 列表渲染 — key 的重要性

```tsx
function List({ items }: { items: { id: number; name: string }[] }) {
  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>{item.name}</li>
      ))}
    </ul>
  )
}
// key 帮助 React 识别哪些元素改变了，必须用稳定唯一标识（不要用 index）
```

> **小结**：能用 JSX 写组件、条件渲染、列表渲染，理解 key 的作用。

## 第二阶段：State、事件与表单（交互）

### 4. useState — 组件内存

```tsx
import { useState } from "react"

function Counter() {
  const [count, setCount] = useState(0)
  return (
    <div>
      <p>{count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount((prev) => prev + 1)}>+1（安全）</button>
    </div>
  )
}

// 核心规则:
// 1. State 更新是异步的 — 同一次事件中的多次 setState 会合并
// 2. 依赖旧值用函数式更新 setState(prev => prev + 1)
// 3. 对象/数组更新需替换（不直接修改原对象）
setUser((prev) => ({ ...prev, name: "Bob" })) // ✅ 新引用
```

### 5. 事件处理

```tsx
function EventDemo() {
  const handleClick = (e: React.MouseEvent) => {
    e.preventDefault() // 阻止默认
    e.stopPropagation() // 阻止冒泡
  }
  return (
    <>
      <button onClick={handleClick}>Click</button>
      <input onChange={(e) => console.log(e.target.value)} />
      <form
        onSubmit={(e) => {
          e.preventDefault()
          submit()
        }}
      >
        <button type="submit">Submit</button>
      </form>
    </>
  )
}
```

### 6. 受控组件 vs 非受控组件

```tsx
// 受控 — 表单值由 React State 控制
const [value, setValue] = useState("")
<input value={value} onChange={e => setValue(e.target.value)} />

// 非受控 — 表单值由 DOM 自身管理
const inputRef = useRef<HTMLInputElement>(null)
<input ref={inputRef} defaultValue="hello" />
// 读取: inputRef.current?.value
```

> **小结**：能用 useState 管理状态、处理事件、写受控表单。

## 第三阶段：useEffect 与副作用（数据获取）

### 7. useEffect 基础

```tsx
import { useEffect } from "react"

// 每次渲染后执行
useEffect(() => {
  console.log("每次渲染")
})

// 仅在挂载时执行一次
useEffect(() => {
  fetchData()
}, [])

// 依赖变化时执行
useEffect(() => {
  console.log(count)
}, [count])

// 清理副作用
useEffect(() => {
  const timer = setInterval(() => tick(), 1000)
  return () => clearInterval(timer) // 卸载/依赖变化前清理
}, [])
```

### 8. 数据获取模式

```tsx
function UserList() {
  const [users, setUsers] = useState([])
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState(null)

  useEffect(() => {
    let cancelled = false
    fetch("/api/users")
      .then((r) => r.json())
      .then((data) => !cancelled && setUsers(data))
      .catch((err) => !cancelled && setError(err))
      .finally(() => !cancelled && setLoading(false))
    return () => {
      cancelled = true
    }
  }, [])

  if (loading) return <div>加载中...</div>
  if (error) return <div>出错了</div>
  return (
    <ul>
      {users.map((u) => (
        <li key={u.id}>{u.name}</li>
      ))}
    </ul>
  )
}
```

## 第四阶段：Hooks 进阶（性能优化核心）

### 9. useRef — 三种用途

```tsx
const inputRef = useRef<HTMLInputElement>(null) // 1. DOM 引用
inputRef.current?.focus()

const timerRef = useRef<number>() // 2. 存储可变值（不触发渲染）
timerRef.current = setInterval(() => {}, 1000)

const prevRef = useRef(value) // 3. 保存上一次的值
useEffect(() => {
  prevRef.current = value
})
```

### 10. useMemo / useCallback / React.memo

```tsx
// useMemo — 缓存计算结果
const sorted = useMemo(() => items.sort(compareFn), [items])

// useCallback — 缓存函数引用（传给 memo 子组件）
const handleClick = useCallback((id) => setSelected(id), [])

// React.memo — props 浅比较，不变则跳过渲染
const MemoChild = React.memo(function Child({ name }: { name: string }) {
  return <div>{name}</div>
})

// ⚠️ memo 失效的头号原因: 每次渲染都创建新引用
// ❌ <Child onClick={() => {}} style={{ color: "red" }} />
// ✅ const onClick = useCallback(...); const style = useMemo(...)
```

### 11. useContext — 跨层级传递

```tsx
const ThemeContext = createContext("light")

function App() {
  return (
    <ThemeContext value="dark">
      <Page />
    </ThemeContext>
  )
}
function Page() {
  const theme = useContext(ThemeContext) // "dark"
  return <div className={theme}>...</div>
}
// ⚠️ Context 值变化时所有消费者都会重渲染，拆分 Context 降低影响范围
```

### 12. useReducer — 复杂状态逻辑

```tsx
type Action = { type: "inc" } | { type: "dec" } | { type: "reset"; payload: number }
function reducer(state: number, action: Action): number {
  switch (action.type) {
    case "inc":
      return state + 1
    case "dec":
      return state - 1
    case "reset":
      return action.payload
  }
}
const [count, dispatch] = useReducer(reducer, 0)
dispatch({ type: "inc" })
// 适合: 多个相关状态、下一个状态依赖前一个、有明确状态过渡规则
```

> **小结**：掌握 useRef/useMemo/useCallback/React.memo/useContext/useReducer 六个进阶 Hooks。

## 第五阶段：组件通信与高级模式

### 13. 五种通信方式

| 方向       | 方式                                 |
| ---------- | ------------------------------------ |
| 父 → 子    | Props                                |
| 子 → 父    | 回调函数 `onData(data)`              |
| 兄弟       | 状态提升到公共父组件                 |
| 跨层级     | Context                              |
| 访问子实例 | `forwardRef` + `useImperativeHandle` |

```tsx
// forwardRef + useImperativeHandle — 暴露自定方法
const Input = forwardRef((props, ref) => {
  const inputRef = useRef<HTMLInputElement>(null)
  useImperativeHandle(ref, () => ({
    focus: () => inputRef.current?.focus(),
    clear: () => {
      if (inputRef.current) inputRef.current.value = ""
    },
  }))
  return <input ref={inputRef} />
})
// 父: inputRef.current?.focus()
```

### 14. HOC / Render Props / 自定义 Hook 选型

```tsx
// 自定义 Hook（首选）— 逻辑复用
function useAuth() {
  const [user, setUser] = useState(null)
  const login = () => fetch("/login").then(setUser)
  return { user, login }
}

// HOC — 注入 props（如 withRouter）
function withAuth(Component) {
  return (props) => {
    const { user } = useAuth()
    return user ? <Component {...props} user={user} /> : <Login />
  }
}
```

### 15. Compound Components — 灵活组合

```tsx
// 让用户自由组装子组件
;<Select value={val} onChange={setVal}>
  <Select.Option value="1">选项1</Select.Option>
  <Select.Option value="2" disabled>
    选项2
  </Select.Option>
</Select>

// 实现: Context 共享状态
const SelectContext = createContext(null)
function Select({ children, value, onChange }) {
  return <SelectContext value={{ value, onChange }}>{children}</SelectContext>
}
Select.Option = ({ children, value }) => {
  const ctx = useContext(SelectContext)
```

| ------------------ | ---------------- | -------------------- |
| `useState`         | 状态             | `[value, setter]`    |

### 性能优化决策树

```
组件渲染慢？ → React.memo
props 中函数每次都新建？ → useCallback
计算开销大且依赖不变？ → useMemo
Context 值频繁变导致全局重渲染？ → 拆分 Context
大型列表？ → 虚拟列表(react-window)
非紧急更新阻塞 UI？ → useTransition
```

## 第十阶段：自定义 Hooks 实战（逻辑复用）

### 23. 常用自定义 Hook 集

```ts
// 数据请求 — 最常用的 Hook
function useFetch<T>(url: string) {
  const [data, setData] = useState<T | null>(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState<Error | null>(null)

  useEffect(() => {
    let cancelled = false
    const controller = new AbortController()
    setLoading(true)
    fetch(url, { signal: controller.signal })
      .then((r) => r.json())
      .then((d) => !cancelled && setData(d))
      .catch((e) => e.name !== "AbortError" && !cancelled && setError(e))
      .finally(() => !cancelled && setLoading(false))
    return () => {
      cancelled = true
      controller.abort()
    }
  }, [url])

  return { data, loading, error }
}

// 防抖
function useDebounce<T>(value: T, delay: number): T {
  const [debounced, setDebounced] = useState(value)
  useEffect(() => {
    const t = setTimeout(() => setDebounced(value), delay)
    return () => clearTimeout(t)
  }, [value, delay])
  return debounced
}

// 前一个值
function usePrevious<T>(value: T): T | undefined {
  const ref = useRef<T>()
  useEffect(() => {
    ref.current = value
  })
  return ref.current
}

// 布尔切换
function useToggle(initial = false) {
  const [on, setOn] = useState(initial)
  return [on, () => setOn((o) => !o), setOn] as const
}

// localStorage 同步
function useLocalStorage<T>(key: string, initial: T) {
  const [value, setValue] = useState<T>(() => {
    try {
      const item = localStorage.getItem(key)
      return item ? JSON.parse(item) : initial
    } catch {
      return initial
    }
  })
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value))
  }, [key, value])
  return [value, setValue] as const
}
```

### 32. "children as prop" 避免重渲染

```tsx
// ❌ 每次渲染都重新创建 SlowComponent
function Parent() {
  const [count, setCount] = useState(0)
  return (
    <div>
      <SlowComponent />
    </div>
  ) // count 变化 → SlowComponent 重渲染
}

// ✅ 用 children 传递 — SlowComponent 不被重新创建
function Layout({ children }) {
  const [count, setCount] = useState(0)
  return <div>{children}</div>
}
function App() {
  return (
    <Layout>
      <SlowComponent />
    </Layout>
  ) // SlowComponent 只渲染一次
}
```

### 33. 避免在渲染中创建函数/对象

```tsx
// ❌ 每次渲染创建新引用 → memo 失效
<Child style={{ color: "red" }} onClick={() => {}} />

// ✅ 提取到外部或缓存
const STYLE = { color: "red" } as const
const handleClick = useCallback(() => {}, [])
<Child style={STYLE} onClick={handleClick} />
```

## 补充速查表

### 类组件生命周期 → Hooks 对照

| 类组件                     | Hooks                                                |
| -------------------------- | ---------------------------------------------------- |
| `constructor`              | `useState(init)` / `useRef`                          |
| `componentDidMount`        | `useEffect(() => {}, [])`                            |
| `componentDidUpdate`       | `useEffect(() => {})` / `useEffect(() => {}, [dep])` |
| `componentWillUnmount`     | `useEffect(() => { return cleanup }, [])`            |
| `shouldComponentUpdate`    | `React.memo` + `useMemo`/`useCallback`               |
| `getDerivedStateFromProps` | 渲染时直接计算                                       |
| `getSnapshotBeforeUpdate`  | `useLayoutEffect`                                    |
| `componentDidCatch`        | Error Boundary（仍用类组件）                         |

### 渲染优化决策树

```
组件渲染慢？
```

## 第十六阶段：Strict Mode 与开发陷阱

### 37. StrictMode 双重挂载

```tsx
<StrictMode>
  <App />

// 开发模式下会: 挂载 → 卸载 → 重新挂载（检测副作用是否正确清理）
// ✅ 正确处理: useEffect return cleanup 中清理
// ❌ 会暴露的问题: 忘记清理的订阅/定时器/事件监听
```

### 38. 常见陷阱速查

```tsx
// 陷阱 1: useState 是异步的
setCount(count + 1)
console.log(count) // 还是旧值！

// 陷阱 2: 对象/数组需要新引用
user.name = "Bob"
setUser(user) // ❌ 不触发渲染
setUser((prev) => ({ ...prev, name: "Bob" })) // ✅

// 陷阱 3: useEffect 中遗漏依赖
useEffect(() => {
  console.log(count)
}, []) // ❌ lint 警告: 缺少 count 依赖

// 陷阱 4: 在循环/条件中调用 Hooks
if (condition) useState(0) // ❌ Hooks 必须在函数顶层、按相同顺序调用

// 陷阱 5: useEffect 中访问最新的 props/state 需用 ref
const latest = useRef(props)
latest.current = props
useEffect(() => {
  const timer = setInterval(() => console.log(latest.current), 1000)
  return () => clearInterval(timer)
}, [])
```
