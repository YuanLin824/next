# CSS 学习指南

> 难度递进式 CSS 学习文档，从盒模型到现代 CSS 工程化。

---

## 第一阶段：盒模型与基础属性（入门）

### 1. 盒模型

```
┌─────────────────────────────┐
│          margin             │
│  ┌───────────────────────┐  │
│  │        border         │  │
│  │  ┌─────────────────┐  │  │
│  │  │     padding     │  │  │
│  │  │  ┌───────────┐  │  │  │
│  │  │  │  content  │  │  │  │ ← width/height 的测量基准取决于 box-sizing
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

```css
/* content-box（默认）: width = content */
/* border-box（推荐）: width = content + padding + border */
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

### 2. 宽高与单位

```css
div {
  width: 200px;
  height: 100px;
} /* 固定像素 */
div {
  width: 50%;
} /* 相对父元素 */
div {
  min-width: 200px;
  max-width: 600px;
} /* 响应式约束 */
div {
  width: 100vw;
  height: 100vh;
} /* 视口宽高 */
div {
  width: fit-content;
} /* 内容自适应宽度 */
```

### 3. 外边距 margin

```css
margin: 10px; /* 四边 */
margin: 10px 20px; /* 上下 左右 */
margin: 10px 20px 30px; /* 上 左右 下 */
margin: 10px 20px 30px 40px; /* 上 右 下 左（顺时针） */
margin: 0 auto; /* 水平居中（需 width） */
```

margin 重叠：**垂直方向**的相邻 margin 取最大值（不是相加）。BFC 或 flex/grid 可阻止。

### 4. 内边距 padding 与边框 border

```css
padding: 16px 24px;
border: 1px solid #ccc;
border-radius: 8px; /* 圆角 */
border-radius: 50%; /* 圆形 */
box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1); /* 阴影 */
```

> **小结**：理解盒模型四层结构，会用基本宽高和 margin/padding/border。

## 第二阶段：选择器与优先级（基础）

### 5. 选择器分类

```css
/* 基础选择器 */
*           /* 通配符 */
div         /* 标签 */
.class      /* 类 */
#id         /* ID */

/* 组合选择器 */
div p       /* 后代（所有 p 后代） */
div > p     /* 子代（直接 p 子元素） */
h1 + p      /* 紧邻下一个兄弟 p */
h1 ~ p      /* 后面所有兄弟 p */

/* 属性选择器 */
[data-type]              /* 有该属性 */
[type="text"]            /* 精确匹配 */
[href^="https"]          /* 以 https 开头 */
[src$=".png"]            /* 以 .png 结尾 */
[class*="btn"]           /* 包含 btn */
[class~="btn"]           /* 包含单词 btn（空格分隔） */

/* 分组 */
h1, h2, h3 {
} /* 多个选择器共享样式 */
```

### 6. 伪类（状态选择器）

```css
a:hover {
} /* 鼠标悬停 */
input:focus {
} /* 获得焦点 */
button:active {
} /* 按下时 */
li:first-child {
} /* 第一个子元素 */
li:last-child {
} /* 最后一个 */
li:nth-child(2) {
} /* 第 2 个 */
li:nth-child(odd) {
} /* 奇数（1,3,5...） */
li:nth-child(even) {
} /* 偶数（2,4,6...） */
li:nth-child(3n + 1) {
} /* 每 3 个一组，选第 1 个 */
input:checked {
} /* 被选中的 checkbox */
input:disabled {
} /* 禁用的表单元素 */
div:empty {
} /* 无子元素的 div */
a:not(.disabled) {
} /* 排除 .disabled 类的 a */
div:has(img) {
} /* 包含 img 的 div（父选择器） */
```

### 7. 伪元素（虚拟元素）

```css
.quote::before {
  content: "「";
} /* 内容前缀 */
.quote::after {
  content: "」";
} /* 内容后缀 */
p::first-letter {
  font-size: 2em;
} /* 首字母 */
p::first-line {
  font-weight: bold;
} /* 首行 */
::selection {
  background: yellow;
} /* 选中文字 */
input::placeholder {
  color: #999;
} /* placeholder */
```

### 8. 优先级计算

```
内联 style (1,0,0,0) > ID (0,1,0,0) > 类/属性/伪类 (0,0,1,0) > 标签/伪元素 (0,0,0,1) > 通配符 (0,0,0,0)
!important > 一切（但应避免使用）
同优先级 → 后者覆盖前者
```

> **小结**：能组合各种选择器，理解优先级计算规则和伪类/伪元素的使用场景。

```css
font-size: 16px;

text-align: left | center | right | justify;

letter-spacing: 0.5px; /* 字间距 */
word-spacing: 2px; /* 词间距 */
white-space: nowrap | pre | pre-wrap;
word-break: break-all | break-word;

.ellipsis {
```

### 11. 颜色表示法


## 第四阶段：布局（核心能力）

### 12. display 属性

| 值             | 独占一行     | 可设宽高 | 典型元素                    |
| -------------- | ------------ | -------- | --------------------------- |
| `block`        | ✅           | ✅       | `div`, `p`, `h1`, `section` |
| `inline`       | ❌           | ❌       | `span`, `a`, `strong`       |
| `inline-block` | ❌           | ✅       | `button`, `input`           |
| `none`         | ❌（不渲染） | —        | 隐藏元素                    |

### 13. position 定位

| 值         | 参照         | 脱离文档流 | 典型用法             |
| ---------- | ------------ | ---------- | -------------------- |
| `static`   | 默认         | ❌         | 默认流               |
| `relative` | 自身原位置   | ❌         | 微调 + absolute 参照 |
| `absolute` | 最近定位祖先 | ✅         | 弹窗/下拉/覆盖       |
| `fixed`    | 视口         | ✅         | 固定导航/回到顶部    |
| `sticky`   | 滚动容器     | ❌         | 吸顶表头             |

```css
/* 绝对居中 */
.center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 14. float 与 clearfix

```css
.float-left {
  float: left;
  margin-right: 16px;
} /* 文字环绕 */
.clearfix::after {
  display: table;
  clear: both;
  content: "";
} /* 清除浮动 */

/* 现代替代：用 flex/grid 代替 float 布局 */
```

### 15. overflow 溢出处理

```css
overflow: visible | hidden | scroll | auto;
overflow-x: auto; /* 横向滚动 */
overflow-y: scroll; /* 纵向滚动 */
```

> **小结**：掌握 display/position/float/overflow 四大布局基础能力。

## 第五阶段：Flexbox（一维布局）

### 16. 容器属性

```css
.container {
  display: flex;
  flex-direction: row | row-reverse | column | column-reverse;
  flex-wrap: nowrap | wrap | wrap-reverse;
  align-content: stretch | flex-start | flex-end | center | space-between;
  justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
  align-items: stretch | flex-start | flex-end | center | baseline;
  gap: 16px; /* row-gap + column-gap */
}
```

### 17. 项目属性

```css
.item {
  flex-grow: 1; /* 放大比例 */
  flex-shrink: 0; /* 不缩小 */
  flex-basis: 200px; /* 初始尺寸 */
  align-self: center; /* 覆盖容器的 align-items */
  order: 1; /* 排列顺序（默认 0） */
}

/* flex 简写 */
flex: 1; /* = flex: 1 1 0（等分） */
flex: 0 0 200px; /* 固定 200px */
flex: 1 1 280px; /* 最小 280px 自动换行 */
```

### 18. 常见 Flex 布局

```css
/* 水平垂直居中 */
.center {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 三栏：侧边固定 + 中间自适应 */
.sidebar {
  flex: 0 0 200px;
}
.content {
  flex: 1;
}

/* 粘性底部 */
.page {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
.main {
  flex: 1;
}

/* 响应式卡片网格 */
.grid {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
.card {
  flex: 1 1 280px;
}
```

> **小结**：能用 Flexbox 实现水平居中、三栏布局、响应式网格等常见场景。

## 第六阶段：Grid（二维布局）

### 19. 容器属性

```css
.container {
  display: grid;
  grid-template-rows: auto 1fr auto; /* 三行 */
  grid-template-columns: 200px 1fr 200px; /* 三列：固定 + 自适应 + 固定 */
  grid-template-columns: repeat(3, 1fr); /* 三等分 */
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); /* 自适应填充 */
  align-items: center; /* 单元格内垂直对齐 */
  justify-items: center; /* 单元格内水平对齐 */
  place-items: center; /* 简写 */
  gap: 16px 24px; /* 行间距 列间距 */
}
```

### 20. 项目属性

```css
.item {
  grid-column: 1 / 3;
} /* 从列线1跨到列线3（占2列） */
.item {
  grid-column: span 2;
} /* 跨 2 列 */
.item {
  grid-row: 1 / 3;
} /* 跨 2 行 */
.item {
  grid-area: header;
} /* 放入命名区域 */
```

### 21. Grid 模板区域

```css
.container {
  display: grid;
  grid-template-rows: 60px 1fr 60px;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}
.header {
  grid-area: header;
}
.sidebar {
  grid-area: sidebar;
}
.main {
  grid-area: main;
}
.footer {
  grid-area: footer;
}
```

### 22. Flex vs Grid 选型

| 场景                     | 推荐             |
| ------------------------ | ---------------- |
| 一维排列（导航/按钮组）  | Flexbox          |
| 二维页面布局（多行多列） | Grid             |
| 数量不定卡片网格         | Grid `auto-fill` |
| 内容驱动宽度             | Flexbox          |

> **小结**：能用 Grid 实现页面级二维布局、命名区域模板和自适应卡片网格。

## 第八阶段：过渡与动画（动效）

### 27. transition 过渡

```css
.btn {
  transition:
    background 0.3s ease,
    transform 0.2s;
}

/* timing-function: ease / linear / ease-in / ease-out / cubic-bezier() */
```

### 28. animation 关键帧动画

```css
.spinner {
  animation: spin 1s linear infinite;
}
@keyframes spin {
  to {
    transform: rotate(360deg);
  }
}

.fade-in {
  animation: fadeIn 0.5s ease both;
}
@keyframes fadeIn {
  from {
    transform: translateY(10px);
    opacity: 0;
  }
}

/* animation 属性拆解:
   name duration timing-function delay iteration-count direction fill-mode */
```

### 29. 性能原则

```txt
✅ 只动画 transform 和 opacity → 仅触发合成（GPU 加速）
❌ 避免动画 width/height/top/left → 触发回流（性能最差）
```

```css
/* ❌ 整页重排 */
.box:hover {
  left: 10px;
  width: 200px;
}
/* ✅ 仅合成 */
.box:hover {
  transform: scale(1.2) translateX(10px);
}
```

## 第九阶段：层叠与格式化上下文（进阶机制）

### 30. BFC（块级格式化上下文）

**触发条件**: `overflow: hidden` / `display: flow-root` / `display: flex` / `position: absolute`
**作用**: 清除浮动、阻止 margin 重叠、自适应两栏布局

```css
.container {
  display: flow-root;
} /* 现代 BFC 最佳方案（无副作用） */
```

### 31. 层叠上下文与 z-index

```css
/* 创建新层叠上下文的常见方式 */
.ctx {
  position: relative;
  z-index: 1;
}
.ctx {
  opacity: 0.99;
}
.ctx {
  transform: scale(1);
}
.ctx {
  isolation: isolate;
} /* 显式创建（最推荐） */
```

### 32. stacking order 层叠顺序

```
z-index 负值 < 块级盒子 < 浮动 < 行内 < z-index: auto/0 < z-index 正值
（同一层叠上下文中）
```

## 第十二阶段：性能与工程化

### 41. 回流（Layout）与重绘（Paint）优化

| 操作              | 触发               | 开销      |
| ----------------- | ------------------ | --------- |
| 改几何属性        | 回流 + 重绘 + 合成 | 高        |
| 改外观属性        | 重绘 + 合成        | 中        |
| transform/opacity | 仅合成             | 低（GPU） |

```css
/* 创建独立合成层 */
.slide {
  will-change: transform;
}
/* ⚠️ 不要滥用（每个层消耗内存），用完移除 */
.slide--done {
  will-change: auto;
}
```

### 42. 选择器性能

```css
/* ✅ 浏览器从右向左匹配，越具体越快 */
.btn-primary {
} /* 快 */
#sidebar .btn {
} /* 慢（先找所有 .btn） */

/* ❌ 避免深层嵌套选择器 */
/* .page .content .sidebar .list .item .title { } */
```

### 隐藏元素对比

| 属性                 | 占空间 | 事件 | 回流 |
| -------------------- | ------ | ---- | ---- |

| `opacity: 0`         | ✅     | ✅   | ❌   |

### 回流/重绘/合成性能谱

```
transform/opacity → 仅合成（最优，GPU）
color/background → 重绘 + 合成
width/height/left/top → 回流 + 重绘 + 合成（最差）
```

### 49. @font-face 自定义字体

```css
@font-face {
  font-style: normal;
  font-weight: 400;
  src:
    url("myfont.woff2") format("woff2"),
    url("myfont.woff") format("woff");
  font-family: "MyFont";
  font-display: swap; /* 关键：不阻塞渲染 */
}

/* font-display 选项:
   auto     — 浏览器默认
   block    — 3s 空白 → 降级
   swap     — 立即用系统字体 → 加载后切换（推荐）

   optional — 100ms 空白 → 可能不下载
*/
```

### @规则速查

| @规则        | 用途       | @规则        | 用途       |
| ------------ | ---------- | ------------ | ---------- |
| `@media`     | 媒体查询   | `@keyframes` | 动画帧     |
| `@container` | 容器查询   | `@font-face` | 字体       |
| `@supports`  | 特性检测   | `@layer`     | 层级控制   |
| `@property`  | 可动画变量 | `@scope`     | 作用域限定 |

### :has() 常用场景

```css
.card:has(img) {
} /* 含图片的卡片 */
body:has(dialog[open]) {
  overflow: hidden;
} /* 弹窗时禁止滚动 */
.form:has(:user-invalid) {
} /* 有校验失败字段 */
```

### 滚动相关属性

| 属性                     | 说明             |
| ------------------------ | ---------------- |
| `scroll-behavior`        | 平滑滚动         |
| `scroll-snap-type/align` | 吸附行为         |
| `overscroll-behavior`    | 过滚动           |
| `animation-timeline`     | 动画绑定滚动     |
| `scroll-timeline`        | 自定义滚动时间线 |
