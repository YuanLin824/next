# Boolean 布尔值

---

## Boolean() — 转为布尔值

```txt
语法: Boolean(value)
参数: value — 任意类型的值
返回: true / false
```

将任意值转换为布尔值，遵循以下规则：

```js
// 以下 8 个值为 false（Falsy），其余全部为 true
Boolean(false) // false
Boolean(0) // false
Boolean(-0) // false
Boolean(0n) // false (BigInt 0)
Boolean("") // false (空字符串)
Boolean(null) // false
Boolean(undefined) // false
Boolean(NaN) // false

// 其余全部为 true（Truthy），包括：
Boolean(true) // true
Boolean(1) // true
Boolean(-1) // true
Boolean(" ") // true (非空字符串，含空格)
Boolean("false") // true (字符串 "false" 是 truthy！)
Boolean([]) // true (空数组)
Boolean({}) // true (空对象)
Boolean(function () {}) // true
Boolean(Infinity) // true
Boolean(-Infinity) // true
```

## Falsy 与 Truthy

### 8 个 Falsy 值

| 值               | 说明      |
| ---------------- | --------- |
| `false`          | 布尔假    |
| `0`              | 数字零    |
| `-0`             | 负零      |
| `0n`             | BigInt 零 |
| `""` / `''` / `` | 空字符串  |
| `null`           | 空值      |
| `undefined`      | 未定义    |
| `NaN`            | 非数字    |

> JS 中**只有这 8 个 Falsy 值**，其余任何值在布尔上下文中都是 `true`。

### 容易被误判的 Truthy

```js
// 这些在布尔上下文中全是 true！
Boolean("0") // true (非空字符串)
Boolean("false") // true (非空字符串)
Boolean([]) // true (空数组)
Boolean({}) // true (空对象)
Boolean(function () {}) // true
Boolean(new Date()) // true
Boolean(Infinity) // true
Boolean(-Infinity) // true
Boolean(" ") // true (含空格的字符串)

// 经典面试题
if ([]) {
  console.log("空数组是 truthy") // 会输出！
}
if ({}) {
  console.log("空对象是 truthy") // 会输出！
}
```

## 显式布尔转换

### 双非运算符 !!

```txt
语法: !!value
原理: 第一个 ! 转为布尔并取反，第二个 ! 再取反恢复原布尔值
```

推荐用 `!!` 做快速布尔转换，等价于 `Boolean()`，更简洁：

```js
!!0 // false
!!1 // true
!!"" // false
!!"hello" // true
!![] // true
!!{} // true
!!null // false
!!undefined // false
```

### Boolean() vs !!

两者完全等价，**推荐在需要强调"布尔转换"语义时用 `Boolean()`**（如 `filter(Boolean)`），在简短表达式中用 `!!`。

```js
// 过滤掉 falsy 值
let arr = [0, 1, "", "hello", null, undefined, NaN, "world"]
arr.filter(Boolean) // [1, "hello", "world"]
// 等价于
arr.filter((item) => !!item) // [1, "hello", "world"]
```

## 布尔包装对象

```txt
语法: new Boolean(value) — 创建布尔包装对象（⚠️ 不推荐）
      Boolean(value)    — 转为原始布尔值（推荐）
```

### new Boolean() 的陷阱 ⚠️

`new Boolean(false)` 创建的是一个**对象**，对象在任何条件下都是 `truthy`：

```js
let boolObj = new Boolean(false)
typeof boolObj // "object"
Boolean(boolObj) // true (对象永远是 truthy！)

// 这会导致非常反直觉的行为
if (boolObj) {
  console.log("意外执行！") // 会输出！
}

// 正确做法
let bool = Boolean(false) // 原始布尔值 false
typeof bool // "boolean"
```

> **永远不要使用 `new Boolean()`**，始终用 `Boolean()` 函数或 `!!`。

### 实例方法

```txt
语法: boolObj.valueOf()   — 返回原始布尔值
      boolObj.toString()  — 返回 "true" / "false" 字符串
参数: 均无
```

```js
let bool = new Boolean(true)
bool.valueOf() // true
bool.toString() // "true"
typeof bool.toString() // "string"
```

## 逻辑运算符中的布尔行为

### && (逻辑与)

从左到右求值，返回**第一个 Falsy 值**，若全为 Truthy 则返回最后一个值。**不会**强制返回 `true`/`false`。

```txt
语法: expr1 && expr2 && ... && exprN
返回: 第一个 Falsy 值，或最后一个表达式的值
```

```js
true && true // true
true && false // false
1 && 0 // 0
1 && 2 && 3 // 3 (全 truthy，返回最后一个)
0 && "hello" // 0 (短路)
null && "hello" // null (短路)

// 实用: 条件执行
isReady && doSomething() // isReady 为 true 时才执行
```

### || (逻辑或)

从左到右求值，返回**第一个 Truthy 值**，若全为 Falsy 则返回最后一个值。

```txt
语法: expr1 || expr2 || ... || exprN
返回: 第一个 Truthy 值，或最后一个表达式的值
```

```js
false || true // true
0 || 1 // 1
"" || "default" // "default"
0 || "" || null // null (全 falsy，返回最后一个)

// 实用: 给变量赋默认值
let name = userInput || "匿名"
```

### ?? (空值合并运算符, ES2020)

与 `||` 类似，但只有 `null` 和 `undefined` 才触发回退（`0`、`""`、`false` 不会）。

```txt
语法: expr1 ?? expr2
返回: expr1 不是 null/undefined 时返回 expr1，否则返回 expr2
```

```js
0 ?? "默认" // 0 (0 不是 null/undefined)
"" ?? "默认" // ""
false ?? true // false
null ?? "默认" // "默认"
undefined ?? "默认" // "默认"

// 对比 ||
0 || "默认" // "默认" (0 是 falsy)
"" || "默认" // "默认"
```

### ! (逻辑非)

```txt
语法: !expr
返回: true / false
```

将操作数转为布尔值后取反，**始终返回 `true` 或 `false`**。

```js
!true // false
!0 // true
!!"hello" // false -> true (等价于 Boolean("hello"))
```

## 条件语句中的隐式转换

`if`、`while`、`do...while`、`for(;;)` 的条件部分，以及三元运算符 `? :` 的条件部分，都会将表达式**隐式转换为布尔值**。

```js
// 以下等价：
if (arr.length > 0) { ... }
if (arr.length) { ... }       // 0 是 falsy, >0 时是 truthy

if (str !== "") { ... }
if (str) { ... }              // "" 是 falsy

if (obj !== null && obj !== undefined) { ... }
if (obj != null) { ... }      // null == undefined
if (obj) { ... }              // null/undefined 都是 falsy

// 注意: 无法区分 0 和不存在
if (value) { ... } // value 为 0 / "" / null / undefined / NaN 都跳过
if (value != null) { ... } // 只区分 null/undefined
```

## 相等比较中的布尔值

### == 宽松相等

使用 `==` 比较时，如果有布尔值，布尔值会**先被转为数字**再比较：

```js
true == 1 // true (Number(true) -> 1)
false == 0 // true
true == 2 // false (1 == 2)
true == "1" // true (Number(true) -> 1, "1" -> 1)
false == "" // true (Number(false) -> 0, "" -> 0)
```

### === 严格相等

类型不同直接返回 `false`，不会进行类型转换：

```js
true === 1 // false
false === 0 // false
true === true // true
```

## 常见易错场景

```js
// 1. 空数组/空对象是 truthy
if ([]) { console.log("Y") } // "Y" — [] 是 truthy！
[]{}.length // undefined -> false (需用 .length 判断是否为空)
// 正确判断空数组: arr.length === 0

if ({}) { console.log("Y") } // "Y" — {} 是 truthy！
// 正确判断空对象: Object.keys(obj).length === 0

// 2. 字符串 "false" 是 truthy
Boolean("false") // true
if ("false") { console.log("执行了") } // 会执行！

// 3. new Boolean(false) 是 truthy（对象）
if (new Boolean(false)) { console.log("执行了") } // 会执行！

// 4. Infinity 和 -Infinity 都是 truthy
Boolean(Infinity) // true
Boolean(-Infinity) // true

// 5. document.all 的特例
typeof document.all // "undefined"
Boolean(document.all) // false (历史遗留的特殊 falsy 对象)
```

## 汇总速查表

| 方法 / 运算符 | 分类     | 用法                 | 返回值               | 说明                  |
| ------------- | -------- | -------------------- | -------------------- | --------------------- |
| `Boolean`     | 转换     | `Boolean(value)`     | `true` / `false`     | 转为布尔值（推荐）    |
| `!!`          | 转换     | `!!value`            | `true` / `false`     | 双非快速转换          |
| `&&`          | 逻辑运算 | `expr1 && expr2`     | 表达式值             | 返回第一个 falsy 值   |
| `\|\|`        | 逻辑运算 | `expr1 \|\| expr2`   | 表达式值             | 返回第一个 truthy 值  |
| `??`          | 逻辑运算 | `expr1 ?? expr2`     | 表达式值             | ES2020，空值合并      |
| `!`           | 逻辑运算 | `!expr`              | `true` / `false`     | 取反，始终返回布尔值  |
| `?:`          | 条件运算 | `condition ? a : b`  | `a` 或 `b`           | 三元运算符            |
| `if/while` 等 | 条件语句 | `if (condition)`     | —                    | condition 隐式转布尔  |
| `==` vs `===` | 相等比较 | `x == y` / `x === y` | `true` / `false`     | `==` 中布尔值先转数字 |
| `valueOf`     | 实例方法 | `boolObj.valueOf()`  | 原始布尔值           | 装箱对象拆箱          |
| `toString`    | 实例方法 | `boolObj.toString()` | `"true"` / `"false"` | 转字符串              |

### 8 个 Falsy 值速记

```
false  0  -0  0n  ""  null  undefined  NaN
```

> 除此之外，一切皆为 Truthy。
