# JavaScript 运算符

---

## 算术运算符

| 运算符 | 说明              | 示例                                |
| ------ | ----------------- | ----------------------------------- |
| `+`    | 加法 / 字符串拼接 | `1 + 2` → `3`，`"a" + "b"` → `"ab"` |
| `-`    | 减法              | `5 - 2` → `3`                       |
| `*`    | 乘法              | `3 * 4` → `12`                      |
| `/`    | 除法              | `10 / 2` → `5`                      |
| `%`    | 取余（模）        | `10 % 3` → `1`                      |
| `**`   | 指数 (ES2016)     | `2 ** 10` → `1024`                  |
| `++`   | 自增              | `x++`（后置）、`++x`（前置）        |
| `--`   | 自减              | `x--`（后置）、`--x`（前置）        |

### 自增/自减的前后置区别

```js
let a = 1
let b = a++ // b = 1, a = 2（先赋值再自增）

let c = 1
let d = ++c // d = 2, c = 2（先自增再赋值）
```

### `+` 运算符的特殊行为

```js
// 字符串拼接优先
"hello" + 42 // "hello42"
"1" + 2 + 3 // "123"（从左到右，"1"+2 → "12"→ "12"+3 → "123"）
1 + 2 + "3" // "33"（1+2 → 3 → 3+"3" → "33"）

// 数值转换
true + true // 2（true → 1）
1 + null // 1（null → 0）
1 + undefined // NaN（undefined → NaN）
1 +
  NaN + // NaN
  // 巧用 + 号转数字
  "42" + // 42
  true + // 1
  null + // 0
  "" // 0
```

## 比较运算符

| 运算符      | 说明                       |
| ----------- | -------------------------- |
| `>` / `<`   | 大于 / 小于                |
| `>=` / `<=` | 大于等于 / 小于等于        |
| `==`        | 宽松相等（类型转换后比较） |
| `!=`        | 宽松不等                   |
| `===`       | 严格相等（类型和值都相同） |
| `!==`       | 严格不等                   |

### == 宽松相等 vs === 严格相等

```txt
===: 类型不同 → 直接返回 false
==: 类型不同 → 先转换再比较
```

### == 转换规则

```js
// 1. null 和 undefined
null == undefined // true
null == 0 // false（null 只等于 undefined 和自己）

// 2. 字符串和数字 → 字符串转数字
"42" == 42 // true
"42" == 43 // false

// 3. 布尔值 → 转数字
true == 1 // true
false == 0 // true
true == 2 // false（1 != 2）

// 4. 对象和原始类型 → 对象转原始类型
;[10] == 10 // true（[10].toString() → "10" → 10）
;[1, 2] == "1,2" // true

// 5. 经典面试题
[] == ![] // true — 解析见下方
[] == false // true（[] → "" → 0, false → 0）
"" == false // true
0 == false // true
```

### [] == ![] 解析

```js
// [] == ![]
// 步骤: ![] → !truthy → false
// [] == false
// ToPrimitive([]) → [].toString() → ""
// "" == false
// Number("") → 0, Number(false) → 0
// 0 == 0 → true
```

### Object.is() — 更精确的相等 (ES2015)

```txt
语法: Object.is(value1, value2)
返回: true / false
```

与 `===` 的区别：

```js
// === 的两个"错误"
;+0 === -0 // true，但 Object.is(+0, -0) // false
NaN === NaN // false，但 Object.is(NaN, NaN) // true

// 其余与 === 一致
Object.is(1, 1) // true
Object.is({}, {}) // false
Object.is(null, null) // true
```

## 逻辑运算符

| 运算符  | 说明                  | 返回值                                |
| ------- | --------------------- | ------------------------------------- |
| `&&`    | 逻辑与                | 第一个 falsy 值，或最后一个 truthy 值 |
| `\|\|`  | 逻辑或                | 第一个 truthy 值，或最后一个 falsy 值 |
| `!`     | 逻辑非                | `true` / `false`（总是布尔值）        |
| `??`    | 空值合并 (ES2020)     | 第一个非 `null`/`undefined` 的值      |
| `&&=`   | 逻辑与赋值 (ES2021)   | `x &&= y` 等价 `x && (x = y)`         |
| `\|\|=` | 逻辑或赋值 (ES2021)   | `x \|\|= y` 等价 `x \|\| (x = y)`     |
| `??=`   | 空值合并赋值 (ES2021) | `x ??= y` 等价 `x ?? (x = y)`         |

### 短路求值 (Short-Circuit)

```js
// && — 遇 falsy 停
1 && 2 && 3 // 3（全 truthy，返回最后一个）
1 && 0 && 3 // 0（遇 falsy 短路）
null && doSomething() // null（doSomething 不会调用）

// || — 遇 truthy 停
0 || "" || "hello" // "hello"（返回第一个 truthy）
1 || 2 || 3 // 1（遇 truthy 短路）

// 实用写法
let name = userInput || "匿名" // 默认值（但 0、"" 也会回退）
let name2 = userInput ?? "匿名" // 空值合并（只有 null/undefined 才回退）
let result = data && data.user && data.user.name // 安全链式访问
```

### || vs ?? 对比

```js
// || — falsy 触发回退
0 || "默认" // "默认"（0 是 falsy）
"" || "默认" // "默认"
false || "默认" // "默认"

// ?? — 仅 null/undefined 触发回退
0 ?? "默认" // 0
"" ?? "默认" // ""
false ?? "默认" // false
null ?? "默认" // "默认"
undefined ?? "默认" // "默认"
```

### 可选链 ?. (ES2020)

```js
// 传统写法
let city = user && user.address && user.address.city

// ?. 写法 — 遇到 null/undefined 短路返回 undefined
let city = user?.address?.city

// 与 ?? 配合
let city = user?.address?.city ?? "未知"

// 函数调用
callback?.()

// 数组索引
arr?.[0]
```

## 位运算符

| 运算符 | 说明       | 示例                      |
| ------ | ---------- | ------------------------- |
| `&`    | 按位与     | `5 & 3` → `1`             |
| `\|`   | 按位或     | `5 \| 3` → `7`            |
| `^`    | 按位异或   | `5 ^ 3` → `6`             |
| `~`    | 按位非     | `~5` → `-6`               |
| `<<`   | 左移       | `1 << 3` → `8`            |
| `>>`   | 有符号右移 | `8 >> 2` → `2`            |
| `>>>`  | 无符号右移 | `-8 >>> 2` → `1073741822` |

> 位运算操作 32 位有符号整数。小数会被截断。

```js
// 实用技巧
// 取整（最快）
3.14 | 0 // 3
~~3.14 // 3
3.14 >> 0 // 3

// 判断奇偶
if (n & 1) {
  /* 奇数 */
}

// 交换两个整数
a ^= b
b ^= a
a ^= b
```

## 三元运算符

```txt
语法: condition ? exprIfTrue : exprIfFalse
```

```js
let status = age >= 18 ? "成年" : "未成年"

// 链式三元（可读性下降，不推荐过度使用）
let level = score >= 90 ? "A" : score >= 80 ? "B" : score >= 60 ? "C" : "D"

// 三元执行函数
isValid ? submit() : showError()
```

## 运算符优先级

从高到低（常用）：

```
1. () 分组
2. . 成员访问 / [] 计算成员 / new / ?.
3. () 函数调用
4. ++ / -- (前置)
5. ! / ~ / + (一元) / - (一元) / typeof / void / delete
6. ** (右结合)
7. * / / %
8. + / -
9. << / >> / >>>
10. < / <= / > / >= / instanceof / in
11. == / != / === / !==
12. &
13. ^
14. |
15. && (短路)
16. || (短路) / ??
17. ? : (三元，右结合)
18. = / += / -= 等赋值 (右结合)
19. , 逗号
```

> `&&` 优先级高于 `||`，所以 `a || b && c` 等价 `a || (b && c)`。

## 汇总速查表

### 相等比较

| 比较                | `==`    | `===`   | `Object.is` |
| ------------------- | ------- | ------- | ----------- |
| `1 == "1"`          | `true`  | `false` | `false`     |
| `null == undefined` | `true`  | `false` | `false`     |
| `NaN == NaN`        | `false` | `false` | `true`      |
| `+0 == -0`          | `true`  | `true`  | `false`     |
| `[] == false`       | `true`  | `false` | `false`     |

### 逻辑运算符速查

| 运算符 | 返回值                         | 短路条件               |
| ------ | ------------------------------ | ---------------------- |
| `&&`   | 第一个 falsy / 最后一个 truthy | 遇 falsy 停            |
| `\|\|` | 第一个 truthy / 最后一个 falsy | 遇 truthy 停           |
| `??`   | 第一个非 null/undefined 的值   | 遇非 null/undefined 停 |
| `!`    | `true` 或 `false`              | —                      |
