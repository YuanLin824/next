# JavaScript 本地存储

---

## 概述

浏览器端四种常用存储方案：

| 方案               | 容量       | 生命周期             | 与服务器通信           | 作用域          | 操作方式              |
| ------------------ | ---------- | -------------------- | ---------------------- | --------------- | --------------------- |
| **Cookie**         | ≤ 4KB      | 可设过期时间         | 每次 HTTP 请求自动携带 | 同源 + path     | `document.cookie`     |
| **sessionStorage** | ~5MB       | 标签页关闭即清除     | 不自动发送             | 同源 + 同标签页 | `setItem` / `getItem` |
| **localStorage**   | ~5MB       | 永久（除非手动清除） | 不自动发送             | 同源            | `setItem` / `getItem` |
| **IndexedDB**      | 理论无上限 | 永久                 | 不自动发送             | 同源            | 异步事务 API          |

---

## Cookie

### 特点

- 大小 ≤ 4KB，每个域名下 cookie 数量通常限制为 20~50 个
- 每次 HTTP 请求都会**自动携带**在 `Cookie` 请求头中，影响性能
- 服务端可通过 `Set-Cookie` 响应头写入
- 可设置过期时间、域名、路径、安全策略

### 属性

| 属性         | 说明                                                   |
| ------------ | ------------------------------------------------------ |
| `name=value` | 键值对（值需 URL 编码）                                |
| `domain`     | 生效域名，默认当前域名（不含子域）                     |
| `path`       | 生效路径，默认当前路径                                 |
| `expires`    | 过期时间（GMT 格式），默认会话结束即失效               |
| `max-age`    | 过期秒数（优先级高于 `expires`）                       |
| `Secure`     | 仅 HTTPS 连接传输                                      |
| `HttpOnly`   | 禁止 JS 访问（`document.cookie` 不可读），仅服务端操控 |
| `SameSite`   | 跨站请求限制：`Strict` / `Lax` / `None`                |

### 读写封装

```js
// 读取 cookie
function getCookie(name) {
  let match = document.cookie.match(new RegExp("(?:^|; )" + name + "=([^;]*)"))
  return match ? decodeURIComponent(match[1]) : null
}

// 写入 cookie
function setCookie(name, value, options = {}) {
  options = {
    path: "/",
    // SameSite: "Lax",
    ...options,
  }

  if (options.expires instanceof Date) {
    options.expires = options.expires.toUTCString()
  }

  let cookieStr = encodeURIComponent(name) + "=" + encodeURIComponent(value)
  for (let key in options) {
    if (!options[key]) continue
    cookieStr += "; " + key
    if (options[key] !== true) {
      cookieStr += "=" + options[key]
    }
  }

  document.cookie = cookieStr
}

// 删除 cookie
function removeCookie(name) {
  setCookie(name, "", { "max-age": 0 })
}

// 使用示例
setCookie("token", "abc123", { "max-age": 3600, Secure: true })
getCookie("token") // "abc123"
removeCookie("token")
```

### 缺陷

- 每次请求都携带，浪费带宽
- 容量极小（4KB）
- 操作繁琐，原生 API 只有 `document.cookie` 一条字符串
- CSRF 攻击风险（需配合 `SameSite` + Token 策略）

## sessionStorage

### 特点

- 容量约 **5MB**
- **标签页级别**：关闭当前标签页即清除，刷新/跳转不丢
- 同源且**同标签页**共享；不同标签页（即使是同源）**不共享**
- 不会随 HTTP 请求自动发送
- 同步 API（阻塞主线程）

### API

```txt
sessionStorage.setItem(key, value)   — 存储，key/value 均为字符串
sessionStorage.getItem(key)          — 读取，返回字符串或 null
sessionStorage.removeItem(key)       — 删除指定键
sessionStorage.clear()               — 清空所有
sessionStorage.key(index)            — 获取第 index 个键名
sessionStorage.length                — 属性，当前存储项数量
```

```js
// 基本操作
sessionStorage.setItem("name", "Alice")
sessionStorage.getItem("name") // "Alice"
sessionStorage.length // 1

// 存储对象需转 JSON
let user = { name: "Alice", age: 18 }
sessionStorage.setItem("user", JSON.stringify(user))
JSON.parse(sessionStorage.getItem("user")) // { name: "Alice", age: 18 }

// 删除
sessionStorage.removeItem("name")
sessionStorage.clear()
```

### 应用场景

- 表单数据暂存（防止刷新丢失）
- 页面间传参（同一标签页内的跨页面，如 A 页面打开 B 页面）
- 敏感数据的短期缓存（关闭即清除）

## localStorage

### 特点

- 容量约 **5MB**（不同浏览器略有差异）
- **持久化存储**：除非手动清除，否则数据永久保留
- 同源**所有标签页共享**
- 不会随 HTTP 请求自动发送
- 同步 API（阻塞主线程），频繁写入大数据会**阻塞渲染**

### API

`localStorage` 的 API 与 `sessionStorage` 完全一致：

```txt
localStorage.setItem(key, value)   — 存储
localStorage.getItem(key)          — 读取
localStorage.removeItem(key)       — 删除指定键
localStorage.clear()               — 清空所有
localStorage.key(index)            — 获取键名
localStorage.length                — 属性，项数
```

```js
// 基本操作
localStorage.setItem("theme", "dark")
localStorage.getItem("theme") // "dark"

// 存储数组/对象
let list = [1, 2, 3]
localStorage.setItem("list", JSON.stringify(list))
JSON.parse(localStorage.getItem("list")) // [1, 2, 3]

// 遍历
for (let i = 0; i < localStorage.length; i++) {
  let key = localStorage.key(i)
  let value = localStorage.getItem(key)
  console.log(key, value)
}

// 批量写入优化（减少同步阻塞）
function batchSet(items) {
  for (let [key, value] of Object.entries(items)) {
    localStorage.setItem(key, value)
  }
}
```

### storage 事件

当**其他同源标签页**修改 `localStorage` 时，当前标签页会触发 `storage` 事件。**当前页面的修改不会触发**自身的事件。

```js
window.addEventListener("storage", (e) => {
  console.log(e.key) // 修改的键名
  console.log(e.oldValue) // 修改前的值
  console.log(e.newValue) // 修改后的值
  console.log(e.url) // 触发事件的页面 URL
  console.log(e.storageArea) // 被修改的 Storage 对象
})
```

> `sessionStorage` 的修改**不会**触发 `storage` 事件（不同标签页不共享，无意义）。

### 存储空间检测

```js
// 检测是否可用
function isStorageAvailable(type = "localStorage") {
  try {
    let storage = window[type]
    let key = "__storage_test__"
    storage.setItem(key, key)
    storage.removeItem(key)
    return true
  } catch (e) {
    return false
  }
}

// 估算已用空间（仅 Chrome）
function getStorageUsage() {
  let total = 0
  for (let i = 0; i < localStorage.length; i++) {
    let key = localStorage.key(i)
    total += key.length + localStorage.getItem(key).length
  }
  // 每个字符 2 字节（UTF-16）
  return total * 2
}
```

### 应用场景

- 用户偏好（主题、语言）
- JWT Token 持久化（注意 XSS 风险，敏感 Token 建议 `HttpOnly` Cookie）
- 草稿自动保存
- 前端路由历史

## IndexedDB

### 特点

- 存储量理论**无上限**（取决于磁盘空间），远超 Cookie/Storage 的 4KB/5MB
- 所有操作**异步**执行，不阻塞主线程
- 支持**事务**（Transaction），保证数据一致性
- 支持**索引**，高效检索
- 原生支持存储 JS 对象（通过结构化克隆算法），无需手动 JSON 序列化
- 支持二进制数据（`Blob`、`File`、`ArrayBuffer`）

### 核心概念

| 概念         | 说明                                   |
| ------------ | -------------------------------------- |
| Database     | 数据库，一个域名可创建多个             |
| Object Store | 对象仓库（类似数据库表），存储实际数据 |
| Key          | 主键（自增或手动指定）                 |
| Index        | 索引，加速查询                         |
| Transaction  | 事务，保证一组操作原子性               |
| Cursor       | 游标，遍历大量数据                     |

### 基本使用流程

```js
// 1. 打开数据库
let request = indexedDB.open("MyDatabase", 1)

// 2. 数据库首次创建或版本升级时触发
request.onupgradeneeded = (e) => {
  let db = e.target.result

  // 创建对象仓库
  if (!db.objectStoreNames.contains("users")) {
    let store = db.createObjectStore("users", {
      keyPath: "id", // 主键字段
      autoIncrement: true, // 主键自增
    })

    // 创建索引
    store.createIndex("nameIndex", "name", { unique: false })
    store.createIndex("emailIndex", "email", { unique: true })
  }
}

// 3. 打开成功
request.onsuccess = (e) => {
  let db = e.target.result
  console.log("数据库打开成功", db)
}

// 4. 打开失败
request.onerror = (e) => {
  console.error("数据库打开失败", e.target.error)
}
```

### CRUD 操作

```js
let db // 已打开的数据库实例

// --- 增 / 改 ---
function putUser(db, user) {
  let tx = db.transaction("users", "readwrite")
  let store = tx.objectStore("users")
  let request = store.put(user) // 存在则更新，不存在则新增

  request.onsuccess = () => console.log("写入成功", request.result)
  request.onerror = () => console.error("写入失败", request.error)

  tx.oncomplete = () => console.log("事务完成")
}

// --- 删 ---
function deleteUser(db, id) {
  let tx = db.transaction("users", "readwrite")
  tx.objectStore("users").delete(id)
  tx.oncomplete = () => console.log("删除完成")
}

// --- 查 (按主键) ---
function getUser(db, id) {
  let tx = db.transaction("users", "readonly")
  let request = tx.objectStore("users").get(id)

  request.onsuccess = () => {
    if (request.result) {
      console.log("查询结果:", request.result)
    } else {
      console.log("未找到")
    }
  }
}

// --- 查 (按索引) ---
function getUserByName(db, name) {
  let tx = db.transaction("users", "readonly")
  let index = tx.objectStore("users").index("nameIndex")
  let request = index.get(name) // 只返回第一个匹配

  request.onsuccess = () => console.log(request.result)
}

// --- 查 (游标遍历) ---
function getAllUsers(db) {
  let tx = db.transaction("users", "readonly")
  let store = tx.objectStore("users")
  let request = store.openCursor()
  let users = []

  request.onsuccess = (e) => {
    let cursor = e.target.result
    if (cursor) {
      users.push(cursor.value)
      cursor.continue() // 移动到下一条
    } else {
      console.log("全部数据:", users)
    }
  }
}
```

### Promise 封装

原生 IndexedDB 基于事件回调，常用封装库如 `idb`，也可以手动封装：

```js
class IDB {
  constructor(name, version, upgradeCallback) {
    this.db = null
    this._ready = new Promise((resolve, reject) => {
      let request = indexedDB.open(name, version)
      request.onupgradeneeded = (e) => upgradeCallback?.(e.target.result, e)
      request.onsuccess = (e) => {
        this.db = e.target.result
        resolve(this.db)
      }
      request.onerror = () => reject(request.error)
    })
  }

  async ready() {
    return this._ready.then(() => this)
  }

  async get(storeName, key) {
    await this._ready
    return new Promise((resolve, reject) => {
      let tx = this.db.transaction(storeName, "readonly")
      let request = tx.objectStore(storeName).get(key)
      request.onsuccess = () => resolve(request.result)
      request.onerror = () => reject(request.error)
    })
  }

  async put(storeName, value) {
    await this._ready
    return new Promise((resolve, reject) => {
      let tx = this.db.transaction(storeName, "readwrite")
      let request = tx.objectStore(storeName).put(value)
      request.onsuccess = () => resolve(request.result)
      request.onerror = () => reject(request.error)
    })
  }

  async delete(storeName, key) {
    await this._ready
    return new Promise((resolve, reject) => {
      let tx = this.db.transaction(storeName, "readwrite")
      let request = tx.objectStore(storeName).delete(key)
      request.onsuccess = () => resolve()
      request.onerror = () => reject(request.error)
    })
  }

  async getAll(storeName) {
    await this._ready
    return new Promise((resolve, reject) => {
      let tx = this.db.transaction(storeName, "readonly")
      let request = tx.objectStore(storeName).getAll()
      request.onsuccess = () => resolve(request.result)
      request.onerror = () => reject(request.error)
    })
  }
}

// 使用
let idb = new IDB("MyApp", 1, (db) => {
  if (!db.objectStoreNames.contains("cache")) {
    db.createObjectStore("cache", { keyPath: "id" })
  }
})

await idb.put("cache", { id: "user_1", data: { name: "Alice" } })
let item = await idb.get("cache", "user_1")
let all = await idb.getAll("cache")
```

### 应用场景

- 离线应用数据存储（PWA）
- 大量结构化数据缓存（如聊天记录、日志）
- 大文件存储（`Blob` / `File`）
- 需要索引和查询性能的场景

## 对比汇总

| 维度                 | Cookie               | sessionStorage       | localStorage        | IndexedDB                  |
| -------------------- | -------------------- | -------------------- | ------------------- | -------------------------- |
| **容量**             | ≤ 4KB                | ~5MB                 | ~5MB                | 理论无上限                 |
| **生命周期**         | 可设过期             | 标签页关闭           | 永久                | 永久                       |
| **作用域**           | 同源 + path          | 同源 + 同标签页      | 同源                | 同源                       |
| **自动发送到服务端** | ✅                   | ❌                   | ❌                  | ❌                         |
| **操作方式**         | 字符串解析           | 同步 API             | 同步 API            | 异步事务 API               |
| **存储数据类型**     | 字符串               | 字符串               | 字符串              | 任意 JS 对象 / Blob / File |
| **是否有索引查询**   | ❌                   | ❌                   | ❌                  | ✅                         |
| **跨标签页通知**     | ❌                   | ❌                   | ✅ (`storage` 事件) | ❌                         |
| **JS 可访问**        | 取决于 `HttpOnly`    | ✅                   | ✅                  | ✅                         |
| **使用场景**         | 会话标识、服务端读取 | 表单暂存、跨页面传参 | 主题、偏好、Token   | 离线应用、大数据缓存       |
