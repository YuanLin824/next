> 难度递进式 JavaScript 学习文档，从语法基础到高级原理。

## 第一阶段：语法基础（入门）

### 1. 变量声明

```js
// var — 函数作用域，可重复声明，有提升
var name = "Alice"
var name = "Bob" // ✅ 可以重复声明

// let — 块作用域，不可重复声明
let age = 18
// let age = 20 // ❌ 报错

// const — 常量，声明时必须赋值，不可重新赋值
const PI = 3.14
// PI = 3.15 // ❌ 报错

// 解构赋值
const [a, b] = [1, 2] // a=1, b=2
const { name, age } = user // name=user.name
const [first, ...rest] = [1, 2, 3] // rest=[2,3]
```

### 2. 数据类型

JS 有 7 种原始类型 + 1 种引用类型：

```js
// 原始类型（栈存储，按值传递）
let str = "hello" // string
let num = 42 // number
let bool = true // boolean
let nothing = null // null — 空值
let notDefined // undefined — 未定义
let sym = Symbol("id") // symbol — 唯一标识
let big = 9007199254740993n // bigint — 大整数

// 引用类型（堆存储，按引用传递）
let obj = { name: "Alice" }
let arr = [1, 2, 3]
let fn = function () {}
```

### 3. 运算符

```js
// 算术: + - * / % ** ++ --
// 比较: > < >= <= == != === !==
// 逻辑: && || ! ??
// 赋值: = += -= *= /=
// 三元: condition ? a : b

// 需要注意的
0.1 + 0.2 // 0.30000000000000004 — 浮点精度
"5" + 3 // "53" — 字符串拼接优先
"5" - 3 // 2 — 减法转数字
0 == false // true — 宽松相等会类型转换
0 === false // false — 严格相等
```

### 4. 条件与循环

```js
// 条件
if (age >= 18) {
  /* 成年 */
} else if (age >= 12) {
  /* 青少年 */
} else {
  /* 儿童 */
}

// switch
switch (color) {
  case "red":
    break
  case "blue":
    break
  default:
    break
}

// 循环
for (let i = 0; i < 10; i++) {}
while (condition) {}
do {} while (condition)

// 遍历数组
for (const item of arr) {
}
arr.forEach((item, i) => {})

// 遍历对象
for (const key in obj) {
}
Object.keys(obj).forEach((key) => {})
```

> **小结**：学完第一阶段，能写基本的变量、运算、条件、循环。

## 第二阶段：函数与作用域（基础进阶）

### 5. 函数定义

```js
// 函数声明（有提升）
function add(a, b) {
  return a + b
}

// 函数表达式（无提升）
const multiply = function (a, b) {
  return a * b
}

// 箭头函数
const divide = (a, b) => a / b

// 参数默认值
function greet(name = "Guest") {
  return `Hi, ${name}`
}
greet() // "Hi, Guest"

// 剩余参数
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0)
}
sum(1, 2, 3) // 6
```

### 6. 作用域与闭包

```js
// 块级作用域
{
  let x = 1
  const y = 2
  var z = 3
}
// x, y 不可访问，z 可访问（var 穿透块）

// 闭包 — 函数记住其词法作用域
function createCounter() {
  let count = 0
  return function () {
    return ++count
  }
}
const counter = createCounter()
counter() // 1
counter() // 2
// count 被闭包"捕获"，外部无法访问
```

### 7. this 指向

```js
// 5 条规则，优先级从高到低：

// 1. new 绑定
function Person(name) {
  this.name = name
}
const p = new Person("Alice")

// 2. 显式绑定 — call / apply / bind
fn.call(thisArg, arg1, arg2)
fn.apply(thisArg, [arg1, arg2])
const bound = fn.bind(thisArg) // 返回新函数

// 3. 隐式绑定 — 对象方法调用
obj.method() // this = obj

// 4. 默认绑定 — 严格模式 undefined，否则 window
fn() // this = window / undefined

// 5. 箭头函数 — 定义时外层作用域
const obj = {
  name: "Alice",
  greet() {
    setTimeout(() => console.log(this.name), 100)
  },
}
obj.greet() // "Alice" — 箭头函数继承外层 this
```

> **小结**：理解闭包原理和 this 的 5 条规则，是 JS 进阶的基础。

## 第三阶段：对象与原型（核心机制）

### 8. 对象操作

```js
// 创建
const obj = { name: "Alice", age: 18 }
const obj2 = new Object()
const obj3 = Object.create(proto)

// 属性访问
obj.name // "Alice"
obj["name"] // "Alice"（动态属性名）

// 遍历
Object.keys(obj) // ["name", "age"] — 自身可枚举
Object.values(obj) // ["Alice", 18]
Object.entries(obj) // [["name","Alice"], ["age",18]]

// 判断
"name" in obj // true（含原型链）
obj.hasOwnProperty("name") // true（仅自身）
```

### 9. 原型链 — JS 继承的核心

```js
function Person(name) {
  this.name = name
}
Person.prototype.sayHi = function () {
  console.log("Hi, " + this.name)
}

const alice = new Person("Alice")
alice.sayHi() // "Hi, Alice"

// 原型链:
// alice.__proto__ === Person.prototype
// Person.prototype.__proto__ === Object.prototype
// Object.prototype.__proto__ === null

// 属性查找: alice.name → 自身有 → 返回
// alice.toString() → 自身无 → Person.prototype 找 → Object.prototype 找 → 找到
```

### 10. 继承的实现

```js
// 寄生组合式继承（ES5 最优方案）
function Parent(name) {
  this.name = name
  this.colors = ["red"]
}
Parent.prototype.sayHi = function () {
  console.log(this.name)
}

function Child(name, age) {
  Parent.call(this, name) // 继承属性
  this.age = age
}
Child.prototype = Object.create(Parent.prototype) // 继承方法
Child.prototype.constructor = Child

// ES6 Class（语法糖，本质同上）
class Parent {
  constructor(name) {
    this.name = name
  }
  sayHi() {
    console.log(this.name)
  }
}
class Child extends Parent {
  constructor(name, age) {
    super(name)
    this.age = age
  }
}
```

> **小结**：理解原型链是理解 JS 一切对象行为的基础。

## 第五阶段：异步编程（核心技能）

### 13. Promise

```js
// 创建 Promise
const promise = new Promise((resolve, reject) => {
  setTimeout(() => resolve("成功"), 1000)
})

// 链式调用
fetch("/api/data")
  .then((res) => res.json())
  .then((data) => console.log(data))
  .catch((err) => console.error(err))
  .finally(() => console.log("结束"))

// 静态方法
Promise.all([p1, p2]) // 全部成功 → 结果数组
Promise.allSettled([p1, p2]) // 全部结束 → 带状态的结果
Promise.race([p1, p2]) // 竞速 — 第一个 settled
Promise.any([p1, p2]) // 任一成功（ES2021）
Promise.resolve(value) // 快速创建已成功 Promise
Promise.reject(error) // 快速创建已失败 Promise
```

### 14. async / await — 更优雅的异步写法

```js
// async 函数 — 自动返回 Promise
async function loadUser(id) {
  try {
    const res = await fetch(`/api/user/${id}`)
    if (!res.ok) throw new Error(`HTTP ${res.status}`)
    const user = await res.json()
    return user
  } catch (err) {
    console.error("加载用户失败:", err)
    throw err
  }
}

// 串行 vs 并行
// 串行（一个等一个）— 总耗时 = sum
const user = await fetchUser()
const posts = await fetchPosts()

// 并行（同时执行）— 总耗时 = max
const [user, posts] = await Promise.all([fetchUser(), fetchPosts()])
```

### 15. 事件循环 — 理解 JS 的异步本质

```
执行一个宏任务（script/setTimeout）→ 清空所有微任务（Promise.then）→ 渲染 → 下一个宏任务
```

```js
console.log("1") // 同步
setTimeout(() => console.log("2"), 0) // 宏任务
Promise.resolve().then(() => console.log("3")) // 微任务
console.log("4")
// 输出: 1 4 3 2
```

> **小结**：Promise 是异步的核心；async/await 是语法糖；事件循环决定了执行顺序。

## 第八阶段：手写核心原理（面试必备）

### 24. call / apply / bind

```js
// call
Function.prototype.myCall = function (ctx, ...args) {
  ctx = ctx || window
  const fn = Symbol()
  ctx[fn] = this
  const result = ctx[fn](...args)
  delete ctx[fn]
  return result
}

// bind
Function.prototype.myBind = function (ctx, ...args1) {
  const self = this
  return function (...args2) {
    return self.apply(ctx, [...args1, ...args2])
  }
}
```

### 25. 深拷贝

```js
function deepClone(obj, map = new WeakMap()) {
  if (typeof obj !== "object" || obj === null) return obj
  if (map.has(obj)) return map.get(obj) // 循环引用

  const clone = Array.isArray(obj) ? [] : {}
  map.set(obj, clone)

  for (const key of Object.keys(obj)) {
    clone[key] = deepClone(obj[key], map)
  }
  // 补充 Symbol 键
  for (const sym of Object.getOwnPropertySymbols(obj)) {
    clone[sym] = deepClone(obj[sym], map)
  }
  return clone
}
```

### 26. 防抖与节流

```js
// 防抖 — 连续触发只执行最后一次
function debounce(fn, delay = 300) {
  let timer
  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => fn.apply(this, args), delay)
  }
}

// 节流 — 固定时间间隔执行一次
function throttle(fn, interval = 100) {
  let last = 0
  return function (...args) {
    const now = Date.now()
    if (now - last >= interval) {
      last = now
      fn.apply(this, args)
    }
  }
}
```

### 27. Promise 简易实现

```js
class MyPromise {
  constructor(executor) {
    this.state = "pending"
    this.value = undefined
    this.callbacks = []

    const resolve = (val) => {
      this.state = "fulfilled"
      this.value = val
      this.callbacks.forEach((cb) => cb.onFulfilled(val))
    }
    const reject = (err) => {
      this.state = "rejected"
      this.value = err
      this.callbacks.forEach((cb) => cb.onRejected(err))
    }

    try {
      executor(resolve, reject)
    } catch (e) {
      reject(e)
    }
  }

  then(onFulfilled, onRejected) {
    return new MyPromise((resolve, reject) => {
      const handler = () => {
        const cb = this.state === "fulfilled" ? onFulfilled : onRejected
        if (typeof cb !== "function") {
          ;(this.state === "fulfilled" ? resolve : reject)(this.value)
          return
        }
        try {
          const result = cb(this.value)
          result instanceof MyPromise ? result.then(resolve, reject) : resolve(result)
        } catch (e) {
          reject(e)
        }
      }
      this.state !== "pending"
        ? setTimeout(handler)
        : this.callbacks.push({ onFulfilled: () => handler(), onRejected: () => handler() })
    })
  }

  catch(onRejected) {
    return this.then(null, onRejected)
  }

  static resolve(val) {
    return new MyPromise((r) => r(val))
  }
  static reject(err) {
    return new MyPromise((_, r) => r(err))
  }
  static all(promises) {
    return new MyPromise((resolve, reject) => {
      const results = []
      let count = 0
      promises.forEach((p, i) =>
        MyPromise.resolve(p).then((v) => {
          results[i] = v
          count++
          if (count === promises.length) resolve(results)
        }, reject)
      )
    })
  }
}
```

> **小结**：手写原理是理解 JS 最深入的方式，面试高频考点。

## 第九阶段：正则表达式（文本处理利器）

### 28. 元字符与量词

```js
// 字符类
\d — 数字    \D — 非数字    \w — 单词字符    \s — 空白
.  — 任意字符（除换行）

// 量词
*   — 0 次或多次    +   — 1 次或多次    ?   — 0 或 1 次
{n} — n 次          {n,} — 至少 n 次    {n,m} — n~m 次

// 锚点
^   — 开头    $ — 结尾    \b — 单词边界

// 贪婪 vs 非贪婪: 默认贪婪（尽可能多），量词后加 ? 变非贪婪

// 常用正则
/^[\w.-]+@[\w-]+(\.[\w-]+)+$/              // 邮箱
/^1[3-9]\d{9}$/                             // 手机号
/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/    // 密码强度
str.replace(/^\s+|\s+$/g, "")               // trim
"camelCase".replace(/([A-Z])/g, "_$1").toLowerCase() // 驼峰转下划线
```

### 29. 捕获组与断言

```js
// 捕获组
"2024-07-16".match(/(\d{4})-(\d{2})-(\d{2})/)  // ["2024-07-16", "2024", "07", "16"]
// 非捕获组 (?:x) — 匹配但不捕获
// 命名捕获组 (?<name>x) — match.groups.name

// 反向引用
/(\w+)\s+\1/.test("hello hello")  // true

// 零宽断言
x(?=y)   // x 后面紧跟 y（正先行）
x(?!y)   // x 后面不是 y（负先行）
(?<=y)x  // x 前面是 y（正后行，ES2018）
// 金额千分位: "12345678".replace(/\B(?=(\d{3})+$)/g, ",") → "12,345,678"
```

### 数据类型判断

| 方法                                | 适用     | 不足          |
| ----------------------------------- | -------- | ------------- |
| `typeof x`                          | 基础类型 | null→"object" |

### 37. 排序算法

```js
// 快速排序
function quickSort(arr) {
  if (arr.length <= 1) return arr
  const pivot = arr[0],
    left = [],
    right = []
  for (let i = 1; i < arr.length; i++) {
    arr[i] < pivot ? left.push(arr[i]) : right.push(arr[i])
  }
  return [...quickSort(left), pivot, ...quickSort(right)]
}

// 归并排序
function mergeSort(arr) {
  if (arr.length <= 1) return arr
  const mid = Math.floor(arr.length / 2)
  return merge(mergeSort(arr.slice(0, mid)), mergeSort(arr.slice(mid)))
}
function merge(left, right) {
  const result = []
  let i = 0,
    j = 0
  while (i < left.length && j < right.length)
    result.push(left[i] < right[j] ? left[i++] : right[j++])
  return [...result, ...left.slice(i), ...right.slice(j)]
}
```

### 43. 发布订阅模式

```js
class EventBus {
  constructor() {
    this.events = {}
  }
  on(event, handler) {
    ;(this.events[event] ||= []).push(handler)
    return () => this.off(event, handler) // 返回取消订阅函数
  }
  off(event, handler) {
    this.events[event] = this.events[event]?.filter((h) => h !== handler)
  }
  emit(event, ...args) {
    this.events[event]?.forEach((h) => h(...args))
  }
  once(event, handler) {
    const wrapper = (...args) => {
      handler(...args)
      this.off(event, wrapper)
    }
    this.on(event, wrapper)
  }
}
```

### 55. 控制并发请求

```js
async function batchRequest(urls, limit = 3) {
  const results = []
  const executing = new Set()

  for (const url of urls) {
    const p = fetch(url)
      .then((r) => r.json())
      .then((d) => results.push(d))
    executing.add(p)
    p.finally(() => executing.delete(p))

    if (executing.size >= limit) {
      await Promise.race(executing) // 等任意一个完成
    }
  }

  await Promise.all(executing) // 等剩余全部完成
  return results
}
```

```js
}
```

### 100. 监控对象所有操作

```js
function watch(obj, onChange) {
  return new Proxy(obj, {
    get(target, key, receiver) {
      const value = Reflect.get(target, key, receiver)
      onChange("get", key, value)
      return typeof value === "object" && value !== null ? watch(value, onChange) : value
    },
    set(target, key, value, receiver) {
      const old = target[key]
      const result = Reflect.set(target, key, value, receiver)
      if (old !== value) onChange("set", key, value, old)
      return result
    },
    deleteProperty(target, key) {
      onChange("delete", key)
      return Reflect.deleteProperty(target, key)
    },
  })
}
```

### 实现并发控制

```js
async function parallelLimit(tasks, limit) {
  const results = []
  const executing = new Set()
  for (const task of tasks) {
    const p = Promise.resolve(task()).then((r) => {
      results.push(r)
      executing.delete(p)
    })
    executing.add(p)
    if (executing.size >= limit) await Promise.race(executing)
  }
  await Promise.all(executing)
  return results
}
```

### 实现 LazyMan

```js
class LazyMan {
  constructor(name) {
    this.tasks = []
    const task = () => {
      console.log(`Hi, ${name}`)
      this.next()
    }
    this.tasks.push(task)
    setTimeout(() => this.next(), 0)
  }
  next() {
    const task = this.tasks.shift()
    task?.()
  }
  sleep(seconds) {
    this.tasks.push(() => {
      setTimeout(() => {
        console.log(`Wake up after ${seconds}s`)
        this.next()
      }, seconds * 1000)
    })
    return this
  }
  eat(food) {
    this.tasks.push(() => {
      console.log(`Eat ${food}`)
      this.next()
    })
    return this
  }
}
```
