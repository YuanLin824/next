# TypeScript 学习指南

> 难度递进式 TypeScript 学习文档，从零基础到高级类型体操。

---

## 第一阶段：基础类型（入门）

### 1. TypeScript 是什么？

TypeScript = JavaScript + **静态类型系统**。在编译时发现类型错误，提供智能代码提示。

```bash
npm install -g typescript
tsc --init   # 生成 tsconfig.json
tsc file.ts  # 编译 TypeScript → JavaScript
```

### 2. 基本类型注解

```ts
// 原始类型
let name: string = "Alice"
let age: number = 18
let isAdmin: boolean = false
let nothing: null = null
let notDefined: undefined = undefined

// 数组 — 两种写法
let nums: number[] = [1, 2, 3]
let strs: Array<string> = ["a", "b"]

// 元组 — 固定长度 + 每项独立类型
let tuple: [string, number] = ["Alice", 18]

// any — 跳过类型检查（尽量避免）
let anything: any = "可以随便变"
anything = 42
anything.toUpperCase() // 不会报错（运行时可能崩溃）

// void — 函数无返回值
function log(msg: string): void {
  console.log(msg)
}
```

### 3. 类型推断

TypeScript 能**自动推断**类型，不需要处处标注：

```ts
let name = "Alice" // string（自动推断）
let count = 0 // number
let items = [1, 2, 3] // number[]
let user = { name: "Alice", age: 18 } // { name: string; age: number }

// 只在必需时才标注
function add(a: number, b: number) {
  // 参数需要标注
  return a + b // 返回值自动推断为 number
}
```

### 4. 联合类型与字面量类型

```ts
// 联合 — 值可以是多种类型之一
let status: "loading" | "success" | "error" = "loading"
let id: string | number = "abc"

// 类型收窄 — 判断后 TypeScript 自动缩小类型范围
function printId(id: string | number) {
  if (typeof id === "string") {
    console.log(id.toUpperCase()) // id 自动收窄为 string
  } else {
    console.log(id.toFixed(0)) // id 自动收窄为 number
  }
}

// ⚠️ 联合类型只能访问共有的属性
function getLength(x: string | number) {
  // x.length // ❌ number 没有 length
  if (typeof x === "string") return x.length // ✅ 收窄后可用
}
```

> **小结**：学完第一阶段，你可以在变量声明后加 `: 类型` 标注类型，理解 `string | number` 联合类型，会用 `typeof` 做类型收窄。

## 第二阶段：接口与类型别名（进阶基础）

### 5. interface — 定义对象形状

```ts
interface User {
  name: string
  age: number
  email?: string // ? 可选属性
  readonly id: number // 只读（创建后不可改）
}

const alice: User = { name: "Alice", age: 18, id: 1 }
// alice.id = 2 // ❌ readonly

// interface 可以同名自动合并
interface User {
  createdAt: Date // 自动合并到上面
}
```

### 6. type — 类型别名

```ts
// type 可以做 interface 的事
type User = {
  name: string
  age: number
}

// type 独有的能力
type Status = "loading" | "success" | "error" // 联合类型
type StringOrNum = string | number
type Callback = (data: string) => void // 函数类型
type Pair = [number, number] // 元组
```

| interface            | type                    |
| -------------------- | ----------------------- |
| ✅ 同名自动合并      | ❌ 同名报错             |
| ✅ 更适合对象结构    | ✅ 更适合联合/交叉/映射 |
| `extends` 扩展       | `&` 交叉扩展            |
| 不能定义原始类型别名 | ✅ `type Name = string` |

### 7. 交叉类型 (`&`)

```ts
type Named = { name: string }
type Aged = { age: number }
type Person = Named & Aged // { name: string; age: number }

// 扩展已有类型
type AdminUser = User & { role: "admin"; permissions: string[] }
```

### 8. 枚举 enum

```ts
// 数字枚举（自增）
enum Direction {
  Up,
  Down,
  Left,
  Right,
} // 0, 1, 2, 3
Direction.Up // 0

// 字符串枚举（可读性更好，推荐）
enum Status {
  Active = "active",
  Inactive = "inactive",
}

// ✅ 更推荐的替代方案（Tree Shaking 友好）
const STATUS = { Active: "active", Inactive: "inactive" } as const
type Status = (typeof STATUS)[keyof typeof STATUS] // "active" | "inactive"
```

> **小结**：interface 定义对象结构；type 更灵活适合联合/元组；`&` 组合类型；枚举用 const + as const 更优。学会用 `?` 可选、`readonly` 只读。

## 第三阶段：函数与泛型入门（核心能力）

### 9. 函数类型

```ts
// 函数声明
function add(a: number, b: number): number {
  return a + b
}

// 函数表达式 — 类型标注
const multiply: (a: number, b: number) => number = (a, b) => a * b

// 可选参数 — ? 标记
function greet(name: string, greeting?: string): string {
  return `${greeting || "Hi"}, ${name}`
}

// 默认参数
function greet(name: string, greeting: string = "Hi"): string {
  return `${greeting}, ${name}`
}

// 剩余参数
function sum(...nums: number[]): number {
  return nums.reduce((a, b) => a + b, 0)
}
```

### 10. 函数重载

同一个函数有多种调用方式：

```ts
// 重载签名（只有签名，没有实现体）
function makeDate(timestamp: number): Date
function makeDate(year: number, month: number, day: number): Date
// 实现签名（兼容所有重载）
function makeDate(a: number, b?: number, c?: number): Date {
  if (b !== undefined && c !== undefined) return new Date(a, b, c)
  return new Date(a)
}

makeDate(1704067200000) // ✅ 一个参数
makeDate(2024, 1, 1) // ✅ 三个参数
// makeDate(2024)               // ❌ 没有匹配的重载
```

### 11. 泛型 — 类型的变量

> 泛型 = 定义时不指定类型，**使用时再确定**。

```ts
// 泛型函数
function identity<T>(arg: T): T {
  return arg
}
const str = identity<string>("hello")
const num = identity(42) // 类型自动推断

// 泛型约束 — T 必须满足某些条件
function getLength<T extends { length: number }>(arg: T): number {
  return arg.length
}
getLength("hello") // ✅ string 有 length
getLength([1, 2, 3]) // ✅ array 有 length
// getLength(42)      // ❌ number 没有 length

// 多个泛型参数
function pair<T, U>(a: T, b: U): [T, U] {
  return [a, b]
}
pair("Alice", 18) // [string, number]
```

### 12. 泛型接口与类型

```ts
// 泛型接口
interface ApiResponse<T> {
  code: number
  data: T
  message: string
}

const userRes: ApiResponse<User> = { code: 0, data: { name: "Alice" }, message: "ok" }
const listRes: ApiResponse<User[]> = { code: 0, data: [{ name: "Alice" }], message: "ok" }

// 泛型类型别名
type Maybe<T> = T | null
type Callback<T> = (data: T) => void
```

> **小结**：函数类型标注参数和返回值；泛型 `<T>` 让函数/接口更通用；`extends` 约束泛型的范围；重载让函数支持多种参数组合。

## 第四阶段：类与面向对象（TypeScript 中的 OOP）

### 13. 类的类型注解

```ts
class User {
  name: string // 必须声明属性类型
  age: number
  private secret: string // 私有

  constructor(name: string, age: number) {
    this.name = name
    this.age = age
    this.secret = "hidden"
  }

  greet(): string {
    return `Hi, I'm ${this.name}`
  }
}

// 参数属性简写（↑ 上面等价于下面一行）
class User {
  constructor(
    public name: string,
    public age: number,
    private secret: string = "hidden"
  ) {}
}
```

### 14. 访问修饰符

| 修饰符        | 自身 | 子类 | 外部             |
| ------------- | ---- | ---- | ---------------- |
| `public`      | ✅   | ✅   | ✅（默认）       |
| `protected`   | ✅   | ✅   | ❌               |
| `private`     | ✅   | ❌   | ❌               |
| `readonly`    | ✅   | ✅   | ✅（不可修改）   |
| `#` (JS 私有) | ✅   | ❌   | ❌（编译后保留） |

```ts
class Animal {
  public name: string
  protected age: number
  private #id: string

  constructor(name: string, age: number) {
    this.name = name
    this.age = age
    this.#id = crypto.randomUUID()
  }
}

class Dog extends Animal {
  bark() {
    console.log(this.name) // ✅ public
    console.log(this.age) // ✅ protected
    // console.log(this.#id) // ❌ # 私有不可访问
  }
}
```

### 15. abstract 抽象类

```ts
abstract class Shape {
  abstract area(): number // 子类必须实现

  describe(): string {
    return `面积: ${this.area()}`
  }
}

class Circle extends Shape {
  constructor(public radius: number) {
    super()
  }
  area() {
    return Math.PI * this.radius ** 2
  }
}
// new Shape() // ❌ 抽象类不可实例化
new Circle(5) // ✅
```

### 16. implements — 类实现接口

```ts
interface Logger {
  log(msg: string): void
  error(msg: string): void
}

class ConsoleLogger implements Logger {
  log(msg: string) {
    console.log(msg)
  }
  error(msg: string) {
    console.error(msg)
  }
}

// 实现多个接口
class AdvancedLogger implements Logger, Disposable {
  // ... 必须实现所有接口的方法
}
```

> **小结**：类属性和方法需要类型标注；`private`/`protected`/`#` 控制访问；`abstract` 强制子类实现；`implements` 实现接口契约。

## 第五阶段：高级类型操作（进阶）

### 17. keyof — 获取对象的所有键

```ts
interface User {
  name: string
  age: number
  email: string
}

type UserKey = keyof User // "name" | "age" | "email"

function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key]
}
const user: User = { name: "Alice", age: 18, email: "a@b.com" }
getProperty(user, "name") // ✅ 类型安全
// getProperty(user, "xxx") // ❌ 编译错误
```

### 18. typeof — 获取值的类型

```ts
const config = { apiUrl: "https://api.example.com", timeout: 3000, retry: 3 }
type Config = typeof config
// { apiUrl: string; timeout: number; retry: number }

const colors = ["red", "green", "blue"] as const
type Color = (typeof colors)[number] // "red" | "green" | "blue"
```

### 19. 索引访问类型

```ts
type User = { name: string; age: number; tags: string[] }

type NameType = User["name"] // string
type TagsType = User["tags"] // string[]
type TagItem = User["tags"][number] // string（数组元素类型）
```

### 20. 条件类型 — `T extends U ? X : Y`

```ts
// 条件类型基础
type IsString<T> = T extends string ? true : false
type A = IsString<"hello"> // true
type B = IsString<42> // false

// 实用：提取 Promise 的值类型
type Awaited<T> = T extends Promise<infer U> ? U : T
type C = Awaited<Promise<string>> // string

// 实用：提取函数返回类型
type ReturnType<T> = T extends (...args: any[]) => infer R ? R : never
type R = ReturnType<() => number> // number
```

### 21. infer — 在条件类型中"提取"类型

```ts
// 提取数组元素类型
type ArrayItem<T> = T extends (infer U)[] ? U : T
type Item = ArrayItem<string[]> // string

// 提取函数第一个参数
type FirstParam<T> = T extends (first: infer F, ...rest: any[]) => any ? F : never
type P = FirstParam<(x: number, y: string) => void> // number

// 提取 Promise 深层值
type DeepAwaited<T> = T extends Promise<infer U> ? DeepAwaited<U> : T
type D = DeepAwaited<Promise<Promise<number>>> // number
```

### 22. 映射类型 — 对已有类型"变换"

```ts
// 手写 Partial — 全部可选
type Partial<T> = { [K in keyof T]?: T[K] }

// 手写 Readonly — 全部只读
type Readonly<T> = { readonly [K in keyof T]: T[K] }

// 手写 Pick — 选取指定属性
type Pick<T, K extends keyof T> = { [P in K]: T[P] }

// 重映射键名 — 给所有属性加 getter
type Getters<T> = { [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K] }
type UserGetters = Getters<{ name: string; age: number }>
// { getName: () => string; getAge: () => number }
```

> **小结**：`keyof` 获取键的联合；`typeof` 获取值的类型；条件类型让类型有"if/else"能力；`infer` 提取类型中的部分；映射类型变换已有类型。

## 第六阶段：模板字面量类型（TS 4.1+）

### 23. 模板字面量类型

```ts
// 拼接字符串类型
type Greeting = `Hello, ${string}` // `Hello, ${string}`
const g1: Greeting = "Hello, World" // ✅
// const g2: Greeting = "Hi, World" // ❌

// 联合类型自动分配 — 产生笛卡儿积
type Color = "red" | "blue"
type Size = "sm" | "lg"
type Variant = `${Color}-${Size}` // "red-sm" | "red-lg" | "blue-sm" | "blue-lg"

// 结合内置字符串操作类型
type EventName = "click" | "change"
type Handler = `on${Capitalize<EventName>}` // "onClick" | "onChange"
```

### 24. 模板字面量的实用场景

```ts
// 1. CSS 单位约束
type CSSValue = `${number}${"px" | "rem" | "vh"}`
const width: CSSValue = "100px" // ✅
// const w: CSSValue = "100abc"   // ❌

// 2. 路由参数类型
type Route = `/user/${string}` | `/post/${number}`
function navigate(path: Route) {}
navigate("/user/alice") // ✅
navigate("/post/123") // ✅
// navigate("/admin")    // ❌

// 3. 链式 Key 路径
type ObjPath<T> = T extends object
  ? { [K in keyof T]: K extends string ? K | `${K}.${ObjPath<T[K]>}` : never }[keyof T]
  : never
```

## 第七阶段：内置工具类型（实用）

### 25. 常用工具类型速查

```ts
interface User {
  name: string
  age: number
  email?: string
}

// 全部可选
type PartialUser = Partial<User> // { name?: string; age?: number; email?: string }

// 全部必填
type RequiredUser = Required<User> // { name: string; age: number; email: string }

// 全部只读
type ReadonlyUser = Readonly<User>

// 选取
type NameAndAge = Pick<User, "name" | "age"> // { name: string; age: number }

// 排除
type WithoutEmail = Omit<User, "email"> // { name: string; age: number }

// 映射
type Page = "home" | "about"
type Nav = Record<Page, string> // { home: string; about: string }

// 联合类型操作
type T1 = Exclude<"a" | "b" | "c", "a"> // "b" | "c"
type T2 = Extract<"a" | "b" | "c", "a" | "b"> // "a" | "b"
type T3 = NonNullable<string | null | undefined> // string

// 函数类型操作
type R = ReturnType<() => string> // string
type P = Parameters<(x: number, y: string) => void> // [number, string]
type A = Awaited<Promise<string>> // string
```

### 26. 工具类型的底层实现

```ts
// 这些内置类型的实现其实很简单：
type Partial<T> = { [K in keyof T]?: T[K] }
type Required<T> = { [K in keyof T]-?: T[K] } // -? 去掉可选
type Readonly<T> = { readonly [K in keyof T]: T[K] }
type Pick<T, K extends keyof T> = { [P in K]: T[P] }
type Record<K extends keyof any, T> = { [P in K]: T }
type Exclude<T, U> = T extends U ? never : T
type Extract<T, U> = T extends U ? T : never
type NonNullable<T> = T extends null | undefined ? never : T
type ReturnType<T extends (...args: any) => any> = T extends (...args: any) => infer R ? R : any
type Parameters<T extends (...args: any) => any> = T extends (...args: infer P) => any ? P : never
type Awaited<T> = T extends Promise<infer U> ? Awaited<U> : T
type Omit<T, K extends keyof any> = Pick<T, Exclude<keyof T, K>>
```

## 第八阶段：类型体操（高级进阶）

### 27. DeepReadonly — 递归只读

```ts
type DeepReadonly<T> = {
  readonly [K in keyof T]: T[K] extends object
    ? T[K] extends Function
      ? T[K]
      : DeepReadonly<T[K]>
    : T[K]
}
```

### 28. DeepPartial — 递归可选

```ts
type DeepPartial<T> = {
  [K in keyof T]?: T[K] extends object ? DeepPartial<T[K]> : T[K]
}
```

### 29. UnionToIntersection — 联合转交叉

```ts
type UnionToIntersection<U> = (U extends any ? (k: U) => void : never) extends (k: infer I) => void
  ? I
  : never
```

### 30. BEM 风格类名生成

```ts
type BEM<B extends string, E extends string[], M extends string[]> =
  | B
  | `${B}__${E[number]}`
  | `${B}--${M[number]}`
  | `${B}__${E[number]}--${M[number]}`

type ButtonClass = BEM<"btn", ["icon", "label"], ["primary", "large"]>
// "btn" | "btn__icon" | "btn__label" | "btn--primary" | "btn--large" | ...
```

### 31. 分布式条件类型

```ts
// 联合类型会"分发"到条件类型
type ToArray<T> = T extends any ? T[] : never
type Result = ToArray<string | number>
// = (string extends any ? string[] : never) | (number extends any ? number[] : never)
// = string[] | number[]  ← 不是 (string|number)[]！
```

### 32. 类型安全的 EventEmitter

```ts
interface EventMap {
  click: { x: number; y: number }
  change: { value: string }
}

class TypedEmitter<T extends Record<string, any>> {
  private handlers = new Map<string, Set<Function>>()

  on<K extends keyof T>(event: K, fn: (args: T[K]) => void) {
    if (!this.handlers.has(event as string)) this.handlers.set(event as string, new Set())
    this.handlers.get(event as string)!.add(fn)
  }
  emit<K extends keyof T>(event: K, args: T[K]) {
    this.handlers.get(event as string)?.forEach((fn) => fn(args))
  }
}
```

## 汇总速查表

### 类型层级（宽 → 窄）

```
unknown → {} / object → 具体类型 → never (最窄)
         any（完全跳过检查）
```

### 类型操作符速查

| 操作符      | 作用                    |
| ----------- | ----------------------- |
| `typeof`    | 值 → 类型               |
| `keyof`     | 对象 → 键的联合         |
| `in`        | 遍历联合                |
| `extends`   | 条件/约束               |
| `infer`     | 提取类型的一部分        |
| `as`        | 类型断言 / 映射键重命名 |

### 62. 类型安全的 Builder 模式

```ts
class RequestBuilder<T extends Record<string, unknown> = {}> {
  private constructor(private options: T) {}

    return new RequestBuilder({})
  }

  }

  }
```

### 63. 类型安全的 Fluent API

```ts
class Query<T = {}, Selected = {}, Where = {}> {
  private constructor(private _typeTag?: T) {}
  static from<T>(): Query<T, {}, {}> {
    return new Query()
  }

  select<K extends keyof T>(...keys: K[]): Query<T, Pick<T, K>, Where> {
    return new Query()
  }
  where<K extends keyof T>(key: K, value: T[K]): Query<T, Selected, Where & Record<K, T[K]>> {
    return new Query()
  }
  execute(): Array<Pick<T, keyof Selected>> {
    return [] as any
  }
}

// 使用 — 类型安全的链式查询

  name: string
  age: number
```

### 64. never 的一些实用模式

```ts
// 1. 确保 switch 穷举 — exhaustive check

  throw new Error(`Unexpected: ${x}`)
}
type Action = { type: "add"; payload: string } | { type: "remove"; id: number }
function reducer(action: Action) {
  switch (action.type) {
    case "add":
      return action.payload
    case "remove":

    default:

  }
}

// 2. 禁止某些属性

}
```

```tsx
interface Props {

const MyInput = forwardRef<HTMLInputElement, Props>(({ label, defaultValue, ...props }, ref) => (

const MyInput = forwardRef<HTMLInputElement, Props>((props, ref) => {

    focus: () => inputRef.current?.focus(),

    },
  }))
```

### 77. useReducer 完整类型

```tsx
type State = { count: number; loading: boolean }
type Action =
  | { type: "increment" }
  | { type: "decrement" }
  | { type: "setLoading"; payload: boolean }

const reducer = (state: State, action: Action): State => {
  switch (action.type) {
    case "increment":
      return { ...state, count: state.count + 1 }
    case "decrement":
      return { ...state, count: state.count - 1 }
    case "setLoading":
      return { ...state, loading: action.payload }
  }
}

const [state, dispatch] = useReducer(reducer, { count: 0, loading: false })
```

## 补充速查表

### tsconfig target 与 lib 对应

| target     | 默认 lib                           |
| ---------- | ---------------------------------- |
| ES5        | DOM, ES5, ScriptHost               |
| ES2015/ES6 | DOM, ES6, DOM.Iterable, ScriptHost |
| ES2020     | DOM, ES2020, ...                   |
| ES2022     | DOM, ES2022, ...                   |

### 模块解析策略

| moduleResolution  | 说明                            |
| ----------------- | ------------------------------- |
| `node`            | 传统 Node.js 解析（需要扩展名） |
| `node16/nodenext` | 支持 package.json exports       |
| `bundler`         | 用于 Vite/Webpack 等打包工具    |
| `classic`         | 已废弃                          |

### 常见 tsconfig 组合

| 场景       | 关键配置                                             |
| ---------- | ---------------------------------------------------- |
| React SPA  | `jsx: "react-jsx"`, `moduleResolution: "bundler"`    |
| Node.js 库 | `module: "NodeNext"`, `declaration: true`            |
| Monorepo   | `composite: true`, `declaration: true`, `references` |
| 仅类型检查 | `noEmit: true`, `skipLibCheck: true`                 |
| 迁移中项目 | `allowJs: true`, `strict: false`                     |

### declare vs export

| 写法                       | 产生 JS | 用途                 |
| -------------------------- | ------- | -------------------- |
| `declare const x: number`  | ❌      | 声明已存在的全局变量 |
| `export const x = 42`      | ✅      | 导出模块变量         |
| `declare module "lib" { }` | ❌      | 声明模块类型         |
| `export type { X }`        | ❌      | 只导出类型           |
