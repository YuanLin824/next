## 第一阶段：文档骨架与基础标签（入门）

### 1. HTML 是什么？

HTML（HyperText Markup Language）是**网页的骨架**——定义内容和结构。浏览器将 HTML 解析为 DOM 树并渲染。

### 2. 最小 HTML5 文档

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>页面标题</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>这是我的第一个 HTML 页面</p>
  </body>
</html>
```

| 标签              | 位置   | 说明                          |
| ----------------- | ------ | ----------------------------- |
| `<!DOCTYPE html>` | 第一行 | 声明 HTML5 文档               |
| `<html>`          | 根元素 | 包裹所有内容                  |
| `<head>`          | 头部   | 元信息（标题/编码/样式/脚本） |
| `<body>`          | 主体   | 用户可见的全部内容            |
| `<meta charset>`  | head   | 字符编码（必填）              |
| `<meta viewport>` | head   | 移动端视口（必填）            |
| `<title>`         | head   | 标签页标题（SEO 关键）        |

### 3. 文本与排版标签

```html
<h1>一级标题</h1>
<!-- 每页一个 h1，SEO 最佳 -->
<h2>二级标题</h2>
<h3>三级</h3>
...
<h6>六级</h6>

<p>段落 — 自动换行和间距</p>
<span>行内容器 — 不换行</span>
<br />
<!-- 换行（无闭合标签） -->
<hr />
<!-- 水平分割线 -->

<strong>语义重要（粗体）</strong>
<em>语义强调（斜体）</em>
<b>纯视觉粗体</b><i>纯视觉斜体</i>
<mark>高亮文本</mark>

<del>删除文本</del> → <ins>插入文本</ins> <sub>下标</sub><sup>上标</sup>
<code>行内代码</code>
<pre>预格式化文本（保留空格和换行）</pre>
<blockquote>块级长引用</blockquote>
<q>行内短引用「自动加引号」</q>
```

### 4. 列表

```html
<!-- 无序列表 -->
<ul>
  <li>项目 1</li>
  <li>项目 2</li>
</ul>

<!-- 有序列表 -->

  <li>第三项</li>
  <li>第二项</li>
</ol>

<!-- 自定义列表（术语-解释对） -->

  <dt>HTML</dt>
  <dd>超文本标记语言</dd>

  <dd>层叠样式表</dd>
</dl>
```

> **小结**: 能写 HTML5 标准文档结构，正确使用标题/段落/列表/文本标签。

## 第二阶段：链接、图片与表格

### 5. 链接 `<a>`

```html
<a href="https://example.com">外部链接</a>
<a href="/about">站内链接</a>
<a href="#section-2">页面内锚点</a>
<a href="mailto:email@example.com">发送邮件</a>
<a href="tel:+8613800138000">拨打电话</a>

<!-- target="_blank" 必须 + rel 防安全问题 -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">新窗口打开</a>
```

| 属性              | 说明                                       |
| ----------------- | ------------------------------------------ |
| `href`            | 链接地址                                   |
| `target="_blank"` | 新窗口/标签页                              |
| `rel`             | 关系（`noopener` `noreferrer` `nofollow`） |
| `download`        | 下载链接目标                               |

### 6. 图片 `<img>` 与响应式

```html
<img
  src="photo.jpg"
  alt="描述（必填，无障碍+SEO+加载失败回退）"
  width="800"
  height="600"
  loading="lazy"
/>
```

| 属性               | 说明                                        |
| ------------------ | ------------------------------------------- |
| `src`              | 图片地址                                    |
| `alt`              | 替换文本（必填！）                          |
| `loading="lazy"`   | 懒加载（视口外不下载）                      |
| `width`/`height`   | 宽高（防 CLS 布局偏移）                     |
| `srcset` + `sizes` | 响应式图片（按屏幕分辨率/宽度选择不同尺寸） |

```html
<!-- 响应式图片 — 不同格式兼容 -->
<picture>
  <source srcset="photo.avif" type="image/avif" />
  <source srcset="photo.webp" type="image/webp" />
  <img src="photo.jpg" alt="描述" />
</picture>
```

### 7. 表格

```html
<table>
  <caption>
    表格标题
  </caption>
  <thead>
    <tr>
      <th scope="col">姓名</th>
      <th scope="col">年龄</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Alice</th>
      <td>18</td>
    </tr>
    <tr>
      <td>Bob</td>
      <td>20</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">共 2 条</td>
    </tr>
  </tfoot>
</table>
```

| 属性              | 说明                    |
| ----------------- | ----------------------- |
| `colspan="2"`     | 跨 2 列合并             |
| `rowspan="2"`     | 跨 2 行合并             |
| `scope="col/row"` | th 的语义方向（无障碍） |

> **小结**: 能用链接/图片/表格，理解 `alt` 必填、`target="_blank"` 安全、响应式图片。

## 第三阶段：表单（交互核心）

### 8. 表单结构

```html
<form action="/submit" method="POST" enctype="multipart/form-data">
  <label for="name">姓名</label>
  <input type="text" id="name" name="name" required minlength="2" placeholder="请输入" />

  <label for="email">邮箱</label>
  <input type="email" id="email" name="email" />

  <fieldset>
    <legend>性别</legend>
    <label><input type="radio" name="gender" value="male" /> 男</label>
    <label><input type="radio" name="gender" value="female" /> 女</label>
  </fieldset>

  <label for="city">城市</label>
  <select id="city" name="city">
    <optgroup label="华北">
      <option value="beijing">北京</option>
    </optgroup>
  </select>

  <label><input type="checkbox" name="agree" required /> 同意协议</label>

  <label for="bio">简介</label>
  <textarea id="bio" name="bio" rows="4" maxlength="500"></textarea>

  <button type="submit">提交</button>
  <button type="reset">重置</button>
  <button type="button">普通按钮</button>
</form>
```

### 9. form 属性

| 属性           | 说明                                  |
| -------------- | ------------------------------------- |
| `action`       | 提交 URL                              |
| `method`       | GET / POST                            |
| `enctype`      | `multipart/form-data`（文件上传必设） |
| `autocomplete` | on / off                              |
| `novalidate`   | 禁用浏览器原生校验                    |

### 10. input type 大全

| type     | 说明                 | type             | 说明       |
| -------- | -------------------- | ---------------- | ---------- |
| `text`   | 文本                 | `password`       | 密码       |
| `email`  | 邮箱（自带格式校验） | `number`         | 数字       |
| `url`    | 网址                 | `tel`            | 电话       |
| `search` | 搜索框               | `date`           | 日期       |
| `time`   | 时间                 | `datetime-local` | 日期+时间  |
| `file`   | 文件上传             | `color`          | 颜色选择器 |
| `range`  | 滑块                 | `checkbox`       | 复选框     |
| `radio`  | 单选框               | `hidden`         | 隐藏字段   |

### 11. 表单校验属性

```html
required 必填 minlength="2" 最少字符 maxlength="20" 最多字符 min="0" max="150" 数值范围
pattern="[a-zA-Z]+" 正则校验 type="email/url" 浏览器自动格式校验
```

> **小结**: 能写完整表单结构，理解 `label` + `for` 关联、`type` 选择、校验属性。

## 第四阶段：语义化与 SEO

### 12. HTML5 语义化布局

```
<header>            — 页头（Logo + 主导航）
<nav>               — 导航链接组
<main>              — 页面主体（每页一个）
  <article>         — 独立内容（博客文章）
  <section>         — 内容分节
  <aside>           — 侧边栏
<footer>            — 页脚（版权/链接）
```

```html
<body>
  <header>
    <h1>我的博客</h1>
    <nav><a href="/">首页</a></nav>
  </header>
  <main>
    <article>
      <h2>文章标题</h2>
      <p>内容...</p>
      <footer>发布于 <time datetime="2024-01-01">1月1日</time></footer>
    </article>
  </main>
  <aside><h3>关于作者</h3></aside>
  <footer><p>(c) 2024</p></footer>
</body>
```

### 13. SEO 优化要点

```html
<!-- 1. 标题层级 -->
<h1>核心关键词 — 每页一个</h1>
<!-- 最重要！ -->

<!-- 2. meta 标签 -->
<meta name="description" content="150 字内的页面描述" />

<!-- 3. Open Graph — 社交分享卡片 -->
<meta property="og:title" content="页面标题" />
<meta property="og:image" content="https://example.com/og.jpg" />

<!-- 4. 结构化数据 JSON-LD — 富文本搜索结果 -->
<script type="application/ld+json">
  { "@context": "https://schema.org", "@type": "Article", "headline": "文章标题" }
</script>

<!-- 5. 图片 alt 必填 -->
<!-- 6. 规范链接 canonical -->
<link rel="canonical" href="https://example.com/original" />

<!-- 7. 语义化标签 + 链接描述性文字 -->
```

> **小结**: 能用语义化标签构建页面结构，掌握 7 条 SEO 优化要点。

## 第六阶段：脚本加载与性能

### 17. script 加载策略

```html
<!-- 普通 — 阻塞 HTML 解析 -->
<script src="app.js"></script>

<!-- defer — 不阻塞，DOM 完成后按顺序执行（推荐业务代码） -->
<script src="app.js" defer></script>

<!-- async — 不阻塞，下载完立即执行（独立脚本/统计） -->
<script src="analytics.js" async></script>

<!-- type="module" — 默认 defer + ES Module -->
<script type="module" src="app.js"></script>
```

| 方式     | 阻塞解析 | 执行顺序            | 适用         |
| -------- | -------- | ------------------- | ------------ |
| 普通     | ✅       | 按出现顺序          | —            |
| `defer`  | ❌       | 按出现顺序 (DOM 后) | **业务代码** |
| `async`  | ❌       | 下载完立即          | 统计/广告    |
| `module` | ❌       | 按依赖图            | ES Module    |

### 18. 资源预加载

```html
<!-- preload — 当前页面必需资源（高优先级） -->
<link rel="preload" href="hero.jpg" as="image" />

<!-- prefetch — 下一页可能用的资源（低优先级） -->
<link rel="prefetch" href="next-page.js" as="script" />

<!-- preconnect — 预热连接（第三方域名） -->
<link rel="preconnect" href="https://api.example.com" />

<!-- dns-prefetch — 仅 DNS 解析 -->
<link rel="dns-prefetch" href="https://cdn.example.com" />
```

> **小结**: defer 放在业务代码，async 给独立脚本，preload 预加载关键资源。

## 第十五阶段：HTML 解析与安全

### 41. 浏览器如何解析 HTML？

```
字节流 (Bytes) → 字符 (Chars) → Token (词法分析) → DOM 节点 → DOM 树
```

关键规则：

- 遇到 `<script>` → 暂停解析，等 JS 下载执行完（除非 async/defer）
- HTML 解析器有容错能力（自动补全缺失标签、忽略不认识的元素）
- CSS 解析不阻塞 DOM 构建，但阻塞 Render 树

### 42. XSS 防范 — HTML 层面的安全

```js
// ❌ 危险 — 用户输入直接插入 HTML
el.innerHTML = userInput // 可能注入 <script> 或 <img onerror=>

// ✅ 安全方式
el.textContent = userInput // 1. 纯文本（推荐）
el.innerHTML = escapeHTML(userInput) // 2. HTML 实体编码
el.innerHTML = DOMPurify.sanitize(userInput) // 3. 净化为安全 HTML
```

class MyCounter extends HTMLElement {
  constructor() {
    super()
    this.count = 0
  }
  connectedCallback() {
    this.innerHTML = `<button>-</button><span>${this.count}</span><button>+</button>`

      this.render()
    }

      this.render()
    }
  }

}

### 54. 资源提示完整指南

```
dns-prefetch → preconnect → preload → fetchpriority

加载顺序:
1. <link rel="preload"> — 当前页必需（最高优先级）
2. fetchpriority="high" — 关键资源优先
3. 默认优先级 — 正常资源
4. <link rel="prefetch"> — 下一页可能用到（空闲时加载）
```
