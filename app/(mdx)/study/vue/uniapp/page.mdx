## 第一阶段：认识 UniApp（入门）

### 1. UniApp 是什么？

DCloud 推出的**跨端框架**，基于 Vue 语法，一套代码编译到 iOS/Android/H5 + 微信/支付宝/百度/字节等小程序。

```
Vue 源码 → UniApp 编译 → 各平台原生代码
```

### 2. 创建项目

```bash
# Vue 3 + Vite + TypeScript（推荐）
npx degit dcloudio/uni-preset-vue#vite-ts my-project
cd my-project && npm install

npm run dev:mp-weixin   # 微信小程序 → 微信开发者工具打开 dist/dev/mp-weixin
npm run dev:h5           # H5 → http://localhost:5173
npm run dev:app          # App
```

### 3. 项目结构

```
src/
├── pages/               # 页面目录（每个页面一个文件夹）
│   └── index/index.vue  # 首页
├── static/              # 静态资源
├── App.vue              # 根组件（应用生命周期）
├── main.ts              # 入口文件
├── pages.json           # 页面路由 + 全局配置（核心文件）
├── manifest.json        # 应用配置
└── uni.scss             # 全局 SCSS 变量
```

### 4. 核心组件（替代 HTML 标签）

```html
<view>
  <!-- div 等价物 -->
  <text>
    <!-- span，文本必须用 text 包裹才能长按选中 -->

        <!-- 按钮，支持 open-type 微信能力 -->

>
```

> **小结**：理解 UniApp 定位（跨端编译框架），能创建项目、了解目录结构和核心组件。

### 6. 路由跳转 API

```ts
// navigateTo — 保留当前页，打开新页（最多 10 层）
uni.navigateTo({ url: "/pages/detail/index?id=123" })

// redirectTo — 关闭当前页，打开新页
uni.redirectTo({ url: "/pages/login/index" })

// switchTab — 跳转到 tabBar 页面
uni.switchTab({ url: "/pages/index/index" })

// navigateBack — 返回
uni.navigateBack({ delta: 1 })

// reLaunch — 关闭所有页面，打开新页面
uni.reLaunch({ url: "/pages/index/index" })
```

### 7. 路由传参

```ts
// 发送 — URL 参数拼接（仅支持字符串）
uni.navigateTo({ url: "/pages/detail/index?id=123&name=hello" })

// 接收 — onLoad 中获取
import { onLoad } from "@dcloudio/uni-app"
onLoad((options) => {
  console.log(options?.id)
})

// 复杂数据 — 全局事件总线或本地存储
uni.setStorageSync("detailData", complexObject)
uni.navigateTo({ url: "/pages/detail/index" })
```

> **小结**：pages.json 管理所有路由，掌握四种跳转 API 和传参方式。

### 14. 网络请求封装

```ts
const BASE_URL = "https://api.example.com"

const request = <T = any>(options: UniApp.RequestOptions): Promise<T> => {
  const token = uni.getStorageSync("token")
  return new Promise((resolve, reject) => {
    uni.request({
      ...options,
      url: `${BASE_URL}${options.url}`,
      header: {
        "Content-Type": "application/json",
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
        ...options.header,
      },
      success: (res) => {
        if (res.statusCode === 200) resolve(res.data as T)
        else if (res.statusCode === 401) {
          uni.reLaunch({ url: "/pages/login/index" })
          reject(res)
        } else {
          uni.showToast({ title: "请求失败", icon: "none" })
          reject(res)
        }
      },
      fail: reject,
    })
  })
}

// 文件上传
await uni.uploadFile({
  url: `${BASE_URL}/upload`,
  filePath,
  name: "file",
  formData: { type: "avatar" },
})
```

## 第十三阶段：实战案例

### 28. 完整分页列表

```vue
<template>
  <view>
    <u-cell-group v-for="item in list" :key="item.id">
      <u-cell :title="item.name" :label="item.desc" isLink @click="goDetail(item.id)" />
    </u-cell-group>
    <u-loadmore :status="loadStatus" @loadmore="loadMore" />
  </view>
</template>

<script setup lang="ts">
import { ref } from "vue"
import { onLoad, onPullDownRefresh, onReachBottom } from "@dcloudio/uni-app"

const list = ref([])
const page = ref(1)
const loadStatus = ref("loadmore") // loadmore | loading | nomore

const fetchData = async () => {
  loadStatus.value = "loading"
  const res = await request({ url: "/api/list", data: { page: page.value, size: 20 } })
  list.value = page.value === 1 ? res.items : [...list.value, ...res.items]
  loadStatus.value = res.items.length < 20 ? "nomore" : "loadmore"
}

onLoad(() => fetchData())
onPullDownRefresh(async () => {
  page.value = 1
  await fetchData()
  uni.stopPullDownRefresh()
})
onReachBottom(() => {
  if (loadStatus.value === "loadmore") {
    page.value++
    fetchData()
  }
})
</script>
```

### 29. 登录 + Token 管理

```ts
// services/auth.ts
export async function login(code: string) {
  const res = await request({ url: "/api/login", method: "POST", data: { code } })
  uni.setStorageSync("token", res.token)
  uni.setStorageSync("userInfo", res.user)
  return res.user
}

export async function checkLogin(): Promise<boolean> {
```
