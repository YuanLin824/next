# Vue 学习指南（Vue 2 & Vue 3）

> 难度递进式 Vue 学习文档，Vue 2 Options API 与 Vue 3 Composition API 对照讲解。

---

## 第一阶段：模板语法与基础指令（入门）

### 1. Vue 是什么？

Vue 是**渐进式 JavaScript 框架**：声明式渲染 → 组件系统 → 路由 → 状态管理 → 构建工具。

```
Vue 2: Options API（data/methods/computed/watch 分选项）
Vue 3: Composition API + Options API（向下兼容 Vue 2 大部分语法）
```

### 2. 创建项目

```bash
# Vue 3（推荐）
npm create vue@latest my-app

# Vue 2
npm create vue@2 my-app
```

### 3. 模板语法

```vue
<template>
  <!-- 插值 {{ }} -->
  <p>{{ message }}</p>
  <p>{{ count + 1 }}</p>

  <!-- 属性绑定 v-bind → : -->
  <img :src="imageUrl" :alt="title" />

  <!-- 事件绑定 v-on → @ -->
  <button @click="increment">+1</button>

  <!-- 双向绑定 v-model -->
  <input v-model="name" />

  <!-- 条件渲染 -->
  <p v-if="score >= 90">优秀</p>
  <p v-else-if="score >= 60">及格</p>
  <p v-else>不及格</p>
  <p v-show="isVisible">频繁切换用 v-show（不销毁 DOM）</p>

  <!-- 列表渲染 -->
  <li v-for="item in items" :key="item.id">{{ item.name }}</li>
</template>
```

### 4. 响应式基础

```js
// Vue 2 Options API
export default {
  data() {
    return { count: 0, user: { name: "Alice" } }
  },
  methods: {
    increment() {
      this.count++
    },
  },
}
```

```vue
<script setup>
// Vue 3 Composition API
import { ref, reactive } from "vue"

const count = ref(0) // ref — 包装原始值，.value 读写
count.value++ // 模板中自动解包，不需 .value
const user = reactive({ name: "Alice" }) // reactive — 包装对象，直接读写
user.name = "Bob"
</script>
```

| 维度     | `ref`                    | `reactive`    |
| -------- | ------------------------ | ------------- |
| 参数类型 | 任意（原始/对象）        | 仅对象/数组   |
| 访问     | `.value`（模板自动解包） | 直接访问      |
| 解构     | 需 `toRefs`              | 需 `toRefs`   |
| 重新赋值 | ✅ `ref.value = newObj`  | ❌ 丢失响应式 |
| 推荐     | **首选**                 | 表单/聚合数据 |

## 第二阶段：计算属性与侦听器

### 5. computed — 派生数据（带缓存）

```js
// Vue 2 Options API
computed: {
  fullName() { return `${this.first} ${this.last}` },       // 只读
  fullName: {                                                 // 可写
    get() { return `${this.first} ${this.last}` },
    set(val) { [this.first, this.last] = val.split(" ") },
  },
}
```

```vue
<script setup>
// Vue 3 Composition API
const fullName = computed(() => `${first.value} ${last.value}`)
const fullName = computed({
  get: () => `${first.value} ${last.value}`,
  set: (val) => {
    ;[first.value, last.value] = val.split(" ")
  },
})
</script>
```

### 6. watch — 数据变化后的副作用

```js
// Vue 2 Options
watch: { count(newVal, oldVal) { console.log(newVal) } }

// Vue 3 Composition
watch(count, (newVal, oldVal) => { console.log(newVal) })
watch(() => state.name, (newVal) => {})         // 侦听 getter
watch([count, name], ([newC, newN]) => {})      // 多源
watch(count, callback, { immediate: true, deep: true }) // 立即 + 深层
```

### 7. watch vs watchEffect (Vue 3)

| 维度     | `watch`                         | `watchEffect`           |
| -------- | ------------------------------- | ----------------------- |
| 指定源   | ✅ 手动指定                     | ❌ 自动追踪回调中的依赖 |
| oldValue | ✅                              | ❌                      |
| 初始执行 | 默认不执行（`immediate: true`） | ✅ 立即执行             |
| 适用     | 知道要监听什么                  | 不知道具体依赖哪些      |

```vue
<script setup>
watchEffect(() => {
  console.log(`count: ${count.value}, name: ${name.value}`)
})
</script>
```

## 第三阶段：组件化与通信

### 8. 组件定义

```vue
<!-- Vue 2 Options API -->
<script>
export default {
  props: ["msg"],
  emits: ["update"],
  data() {
    return { count: 0 }
  },
  methods: {
    handleClick() {
      this.$emit("update", this.count)
    },
  },
}
</script>
```

```vue
<!-- Vue 3 <script setup>（推荐） -->
<script setup lang="ts">
const props = defineProps<{ msg: string; count?: number }>()
withDefaults(defineProps<{ count?: number }>(), { count: 0 })
const emit = defineEmits<{ (e: "update", val: number): void }>()
</script>
```

### 9. 组件通信六种方式

| 方向     | Vue 2                           | Vue 3                 |
| -------- | ------------------------------- | --------------------- |
| 父→子    | Props                           | Props / `defineProps` |
| 子→父    | `$emit`                         | `defineEmits`         |
| 双向     | `.sync` 修饰符                  | `v-model:propName`    |
| 跨层级   | provide/inject                  | provide/inject        |
| 全局事件 | `$on/$emit/$off`（已移除）      | mitt 库替代           |
| 访问实例 | `$refs` / `$children`（已移除） | `ref(null)`           |

```vue
<!-- v-model 双向绑定 → Vue 3 支持多个 -->
<Child v-model:title="title" v-model:content="content" />
<!-- 子: defineProps(["title","content"]); emit("update:title", val) -->

<!-- provide / inject — 跨层级 -->
<script setup>
provide("key", value)
</script>
<!-- 祖先 -->
<script setup>
const val = inject("key")
</script>
<!-- 后代 -->
```

### 10. 插槽

```vue
<!-- 默认插槽 -->
<slot>默认内容</slot>
<!-- 具名插槽 -->
<slot name="header" />
<!-- 作用域插槽 -->
<slot :data="item" />

<!-- 使用 -->
<Child>
  <template #header>标题</template>       <!-- 具名 v-slot:header → #header -->
  <template #default="{ data }">{{ data }}</template> <!-- 作用域 -->
</Child>
```

## 第四阶段：生命周期

| Vue 2 Options   | Vue 3 Composition | 说明            |
| --------------- | ----------------- | --------------- |
| `beforeCreate`  | `setup()` 本身    | 组件创建前      |
| `created`       | `setup()` 本身    | 创建完成        |
| `beforeMount`   | `onBeforeMount`   | DOM 挂载前      |
| `mounted`       | `onMounted`       | DOM 挂载完成    |
| `beforeUpdate`  | `onBeforeUpdate`  | 数据更新前      |
| `updated`       | `onUpdated`       | 数据更新后      |
| `beforeDestroy` | `onBeforeUnmount` | 组件销毁前      |
| `destroyed`     | `onUnmounted`     | 组件销毁后      |
| `activated`     | `onActivated`     | keep-alive 激活 |
| `deactivated`   | `onDeactivated`   | keep-alive 停用 |

**父子组件执行顺序**：父 beforeCreate → 父 created → 父 beforeMount → 子 创建+挂载 → 父 mounted

## 第七阶段：Hooks 与自定义 Hook

### 16. 自定义 Hook（Composable）

```ts
// hooks/useMouse.ts
import { ref, onMounted, onUnmounted } from "vue"

export function useMouse() {
  const x = ref(0)
  const y = ref(0)
  const update = (e: MouseEvent) => {
    x.value = e.pageX
    y.value = e.pageY
  }
  onMounted(() => window.addEventListener("mousemove", update))
  onUnmounted(() => window.removeEventListener("mousemove", update))
  return { x, y }
}
```

```vue
<script setup>
const { x, y } = useMouse()
</script>
```

## 第八阶段：进阶响应式 API

| API               | 说明                                            |
| ----------------- | ----------------------------------------------- |
| `shallowRef`      | 浅响应式（`.value` 变化才触发，内部属性不响应） |
| `shallowReactive` | 浅响应式（仅第一层属性响应）                    |
| `readonly`        | 返回响应式的只读代理                            |
| `toRaw`           | 响应式对象 → 原始对象                           |
| `markRaw`         | 标记对象永不成为响应式                          |
| `customRef`       | 自定义 ref（控制 track/trigger 时机）           |
| `toRef(obj, key)` | 提取响应式对象的单个属性为 ref                  |
| `toRefs(obj)`     | 提取响应式对象的所有属性为 ref                  |

```ts
// customRef — 防抖 ref
function useDebouncedRef(value, delay = 200) {
  let timer
  return customRef((track, trigger) => ({
    get() {
      track()
      return value
    },
    set(val) {
      clearTimeout(timer)
      timer = setTimeout(() => {
        value = val
        trigger()
      }, delay)
    },
  }))
}
```

```
数据是原始类型？ → ref
```

### 21. 自定义指令

```ts
// Vue 2 — 全局指令 Vue.directive("focus", { inserted(el) { el.focus() } })
// Vue 3 — app.directive
app.directive("focus", {
  mounted(el) {
    el.focus()
  },
})

app.directive("lazy", {
  mounted(el, binding) {
    const observer = new IntersectionObserver(([entry]) => {
      if (entry.isIntersecting) {
        el.src = binding.value
        observer.unobserve(el)
      }
    })
    observer.observe(el)
  },
})
```

```vue
<!-- 使用 -->
<input v-focus />
<img v-lazy="imageUrl" />
```

| 指令钩子 (Vue 3) | 说明                |
| ---------------- | ------------------- |
| `created`        | 元素属性/事件创建前 |
| `mounted`        | 元素插入 DOM        |
| `updated`        | 组件更新后          |
| `beforeUnmount`  | 元素移除前          |
| `unmounted`      | 元素移除后          |

## 第十五阶段：Vue 3 响应式原理

### 25. Vue 2 Object.defineProperty 的缺陷

```js
// Vue 2 无法检测：
// 1. 属性新增/删除 → 需 Vue.set / Vue.delete
// 2. 数组索引赋值 / length 修改 → 7 个变异方法重写
// 3. 初始化时递归所有属性 → 深层对象性能差
```

### 26. Vue 3 Proxy 优势

```js
// 简化实现
function reactive(obj) {
  return new Proxy(obj, {
    get(target, key, receiver) {
      track(target, key) // 依赖收集
      const result = Reflect.get(target, key, receiver)
      return typeof result === "object" && result !== null ? reactive(result) : result // 懒代理
    },
    set(target, key, value, receiver) {
      const old = target[key]
      const result = Reflect.set(target, key, value, receiver)
      if (old !== value) trigger(target, key) // 派发更新
      return result
    },
  })
}
```

| 能力            | Vue 2 defineProperty  | Vue 3 Proxy            |
| --------------- | --------------------- | ---------------------- |
| 新增/删除属性   | ❌ Vue.set/Vue.delete | ✅                     |
| 数组索引/长度   | ❌                    | ✅                     |
| 性能            | 递归劫持所有属性      | 懒代理（访问时才递归） |
| Map/Set/WeakMap | ❌                    | ✅                     |
| IE 兼容         | ✅ IE9+               | ❌ Proxy 不可 polyfill |

### 32. 组件 v-model 实现原理

```vue
<!-- v-model 等价于 -->
<input :value="text" @input="text = $event.target.value" />

<!-- 组件上的 v-model -->
<CustomInput :modelValue="text" @update:modelValue="text = $event" />
```

### 33. Vue 3 多 v-model

```vue
<!-- 父 -->
<Child v-model:title="t" v-model:content="c" />

<!-- 子 -->
<script setup>
defineProps(["title", "content"])
const emit = defineEmits(["update:title", "update:content"])
// 触发: emit("update:title", newVal)
</script>
```

### 34. v-model 修饰符

```vue
<!-- 子组件接收修饰符 -->
<script setup>
const props = defineProps({ modelValue: String, modelModifiers: { default: () => ({}) } })
const emit = defineEmits(["update:modelValue"])
function emitValue(e) {
  let val = e.target.value
  if (props.modelModifiers.capitalize) val = val.toUpperCase()
  if (props.modelModifiers.trim) val = val.trim()
  emit("update:modelValue", val)
}
</script>
<!-- <Child v-model.capitalize.trim="text" /> -->
```

### 35. SSR vs CSR 对比

| 维度       | CSR (Vue SPA)         | SSR (Nuxt)              |
| ---------- | --------------------- | ----------------------- |
| 首屏速度   | 慢（等 JS 下载+执行） | 快（服务端返回 HTML）   |
| SEO        | 差（爬虫不易抓取）    | ✅ 完美                 |
| 服务器压力 | 低（纯静态文件）      | 高（需 Node.js 服务器） |
| 适用       | 后台管理系统          | 官网/博客/电商          |

```bash
npx nuxi init my-app && cd my-app && npm install && npm run dev
```
