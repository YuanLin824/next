## 第一阶段：认识 Taro（入门）

### 1. Taro 是什么？

京东开发的**跨端跨框架**解决方案：一套 React/Vue 代码 → 编译到微信/支付宝/百度/字节/QQ/京东小程序 + H5 + React Native。

```
React/Vue 源码 → Babel/SWC 编译 → Taro 中间代码 → 各平台原生代码
```

### 2. 创建项目

```bash
npm install -g @tarojs/cli
taro init myApp
# 选择: React + TypeScript + Sass + 默认模板

npm run dev:weapp  # 微信小程序 → 用微信开发者工具打开 dist 目录
npm run dev:h5      # H5 → 浏览器 http://localhost:10086
npm run build:weapp # 生产构建
```

### 3. 项目结构

```
src/
├── app.config.ts       # 全局配置: pages 路由/window/tabBar/分包
├── app.tsx             # App 入口（生命周期 useLaunch）
├── app.scss            # 全局样式
├── pages/
│   └── index/
│       ├── index.tsx          # 页面组件
│       ├── index.config.ts    # 页面配置
│       └── index.scss         # 页面样式
config/
├── index.ts             # 主配置: designWidth=750, compiler
├── dev.ts               # 开发环境
└── prod.ts              # 生产环境
```

### 4. 核心 Taro 组件（替代 HTML 标签）


### 6. 页面导航（四种跳转方式）

```tsx
import Taro from "@tarojs/taro"

// navigateTo — 保留当前页，打开新页（最多 10 层）
Taro.navigateTo({ url: "/pages/detail/index?id=123" })

// redirectTo — 关闭当前页，打开新页（不可返回）
Taro.redirectTo({ url: "/pages/login/index" })

// switchTab — 跳转到 tabBar 页面（关闭所有非 tabBar 页）
Taro.switchTab({ url: "/pages/index/index" })

// navigateBack — 返回上一页
Taro.navigateBack({ delta: 1 })

// reLaunch — 关闭所有页面，打开新页面
Taro.reLaunch({ url: "/pages/index/index" })
```

### 7. 路由传参

```tsx
// 复杂数据 — 通过 globalData 或本地存储传递
```

### 8. 页面生命周期 Hooks

```tsx

  useDidShow,
  useDidHide,

  useReachBottom,
  usePageScroll,
```


### 14. 网络请求封装

```tsx
const BASE_URL = "https://api.example.com"

const request = (options: Taro.request.Option): Promise<any> => {
  const token = Taro.getStorageSync("token")
  return new Promise((resolve, reject) => {
    Taro.request({
      ...options,
      url: `${BASE_URL}${options.url}`,
      header: {
        "Content-Type": "application/json",
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
        ...options.header,
      },
      success(res) {
        if (res.statusCode === 200) resolve(res.data)
        else if (res.statusCode === 401) {
          Taro.reLaunch({ url: "/pages/login/index" })
          reject(res)
        } else {
          Taro.showToast({ title: "请求失败", icon: "none" })
          reject(res)
        }
      },
      fail(err) {
        Taro.showToast({ title: "网络异常", icon: "none" })
        reject(err)
      },
    })
  })
}

// 使用
const data = await request({ url: "/api/users", method: "GET", data: { page: 1 } })
```

### 16. 自定义 Hooks

```tsx
// 获取页面参数
function usePageParams<T>() {
  const [params] = useState<T>((Taro.getCurrentInstance().router?.params as T) ?? ({} as T))
  return params
}

// 下拉刷新
function useRefresh(fetchFn: () => Promise<void>) {
  const [refreshing, setRefreshing] = useState(false)
  usePullDownRefresh(async () => {
    setRefreshing(true)
    await fetchFn()
    setRefreshing(false)
    Taro.stopPullDownRefresh()
  })
  return { refreshing }
}

// 倒计时
function useCountdown(seconds: number) {
  const [count, setCount] = useState(seconds)
  const [running, setRunning] = useState(false)
  useEffect(() => {
    if (!running || count <= 0) return
    const timer = setInterval(() => setCount((c) => c - 1), 1000)
    return () => clearInterval(timer)
  }, [running])
  return {
    count,
    start: () => setRunning(true),
    reset: () => {
      setRunning(false)
      setCount(seconds)
    },
  }
}
```

## 第十阶段：实战案例集

### 29. 完整分页列表

```tsx
function PagedList() {
  const [list, setList] = useState([])
  const [page, setPage] = useState(1)
  const [loading, setLoading] = useState(false)
  const [hasMore, setHasMore] = useState(true)

  const fetchData = useCallback(async () => {
    if (loading || !hasMore) return
    setLoading(true)
    try {
      const res = await request({ url: "/api/list", data: { page, size: 20 } })
      setList((prev) => (page === 1 ? res.items : [...prev, ...res.items]))
      setHasMore(res.items.length === 20)
    } finally {
      setLoading(false)
    }
  }, [page])

  useEffect(() => {
    fetchData()
  }, [page])

  usePullDownRefresh(async () => {
    setPage(1)
    setHasMore(true)
    await fetchData()
    Taro.stopPullDownRefresh()
  })
  useReachBottom(() => {
    if (!loading && hasMore) setPage((p) => p + 1)
  })

  return (
    <ScrollView
      scrollY
      onScrollToLower={() => {
        if (!loading && hasMore) setPage((p) => p + 1)
      }}
    >
      {list.map((item) => (
        <Item key={item.id} data={item} />
      ))}
      {loading && <View>加载中...</View>}
      {!hasMore && <View>没有更多了</View>}
    </ScrollView>
  )
}
```

### 31. 登录 Token 管理

```ts
// 登录
async function login() {
  const { code } = await Taro.login()
  const res = await request({ url: "/api/login", method: "POST", data: { code } })
  Taro.setStorageSync("token", res.token)
}

// 请求拦截器
function request(options: Taro.request.Option): Promise<any> {
  const token = Taro.getStorageSync("token")
  return new Promise((resolve, reject) => {
    Taro.request({
      ...options,
      header: { Authorization: token ? `Bearer ${token}` : "", ...options.header },
      success: async (res) => {
        if (res.statusCode === 401) {
          await login()
          return resolve(request(options))
        }
        resolve(res.data)
      },
      fail: reject,
    })
  })
}
```

```tsx
  {/* <View>裸文本</View> — RN 报错！ */}
</View>
```

## 第十二阶段：常见坑与排查

### 34. 常见问题速查

| 问题                  | 原因                      | 方案                                |
| --------------------- | ------------------------- | ----------------------------------- |
| 样式不生效            | 小程序不支持某些 CSS 属性 | 查官方兼容表                        |
| setState 后页面不更新 | 引用相同未创建新对象      | `setObj(prev => ({...prev, a: 1}))` |
| 图片不显示            | 小程序不支持本地图作背景  | 用 `<Image>` 或 base64              |
| 分包页面 404          | 主包未正确配置分包路径    | 检查 subPackages.root               |
| H5 端 Storage 不同    | 各平台 Storage 隔立       | 需自行同步                          |
| 页面栈超 10 层        | navigateTo 次数超限       | 改用 redirectTo 或 reLaunch         |
