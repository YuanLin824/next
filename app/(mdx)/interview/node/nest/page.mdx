## 基础概念

### Q1: 什么是 NestJS？它的核心设计理念是什么？

NestJS 是 Node.js 服务端框架，基于 **Express/Fastify**，使用 **TypeScript**，借鉴了 Angular 的架构思想。核心理念：

- **模块化**（`@Module`）— 将应用拆分为独立的功能模块
- **依赖注入**（DI）— 通过 IoC 容器管理实例创建和依赖关系
- **装饰器**— `@Controller`、`@Injectable`、`@Inject` 等声明式编程
- **面向对象**— Controller / Service / Module 清晰分层

### Q2: NestJS 的请求生命周期是怎样的？

```
请求进入
  → Middleware（中间件）
  → Guard（守卫 — 鉴权）
  → Interceptor（拦截器 — before）
  → Pipe（管道 — 参数校验/转换）
  → Controller（控制器 — 路由处理）
  → Service（业务逻辑）
  → Interceptor（拦截器 — after）
  → ExceptionFilter（异常过滤器 — 兜底）
  → 响应返回
```

| 组件            | 职责          | 典型场景                     |
| --------------- | ------------- | ---------------------------- |
| Middleware      | 请求预处理    | 日志、CORS、body-parser      |
| Guard           | 鉴权          | JWT 验证、角色检查           |
| Interceptor     | 请求/响应包裹 | 响应格式化、缓存、耗时统计   |
| Pipe            | 参数校验/转换 | ValidationPipe、ParseIntPipe |
| ExceptionFilter | 异常统一处理  | 统一错误响应格式             |

### Q3: NestJS 和 Express 的关系是什么？和 Fastify 呢？

NestJS **底层默认使用 Express**，也可以切换为 **Fastify**（性能更好）。

| 维度             | Express  | Fastify (NestJS 可切换) | NestJS                            |
| ---------------- | -------- | ----------------------- | --------------------------------- |
| 开发方式         | 自由组织 | 自由组织                | 结构化（模块/Controller/Service） |
| TypeScript       | 手动支持 | 手动支持                | 原生 TS + 装饰器                  |
| DI / IoC         | ❌       | ❌                      | ✅ 内置                           |
| 性能             | 一般     | 高                      | 取决于底层（Express 或 Fastify）  |
| OpenAPI(Swagger) | 手动     | 手动                    | `@nestjs/swagger` 自动生成        |

```typescript
// 切换到 Fastify
import { NestFactory } from "@nestjs/core"
import { FastifyAdapter } from "@nestjs/platform-fastify"
import { AppModule } from "./app.module"

async function bootstrap() {
  const app = await NestFactory.create(AppModule, new FastifyAdapter())
  await app.listen(3000)
}
```

## 模块与依赖注入

### Q4: @Module 有哪些属性？分别什么作用？

```typescript
@Module({
  imports: [UserModule, ConfigModule.forRoot()], // 导入其他模块（导出内容注入当前模块）
  controllers: [UserController], // 注册控制器
  providers: [UserService, LoggerService], // 注册提供者（可被注入）
  exports: [UserService], // 导出提供者（供其他模块使用）
})
export class UserModule {}
```

| 属性          | 说明                                              |
| ------------- | ------------------------------------------------- |
| `imports`     | 导入其他模块，使该模块的 `exports` 在当前模块可用 |
| `controllers` | 注册路由处理器                                    |
| `providers`   | 注册可注入的服务、工厂、值等                      |
| `exports`     | 将当前模块的 provider 暴露给导入者                |

### Q5: NestJS 的依赖注入是如何工作的？

NestJS 的 IoC 容器通过 **Provider Token** 管理依赖关系：

```typescript
// 1. 类 Provider（最常见 — token 就是类本身）
@Injectable()
export class UserService {
  findAll() { return [] }
}

@Controller("users")
export class UserController {
  constructor(private readonly userService: UserService) {} // 自动注入
}

// 2. 自定义 Token
@Module({
  providers: [
    { provide: "CONFIG", useValue: { port: 3000 } },
    { provide: "LOGGER", useClass: DevLogger },
    { provide: "DB", useFactory: (config) => createConnection(config), inject: ["CONFIG"] },
  ],
})
```

| Provider 类型 | 语法                                                | 说明                          |
| ------------- | --------------------------------------------------- | ----------------------------- |
| `useClass`    | `{ provide: Token, useClass: Class }`               | 注入指定类的实例              |
| `useValue`    | `{ provide: Token, useValue: value }`               | 注入固定值                    |
| `useFactory`  | `{ provide: Token, useFactory: fn, inject: [...] }` | 工厂函数创建                  |
| `useExisting` | `{ provide: Token, useExisting: Alias }`            | 别名，实际指向另一个 provider |

```typescript
// 注入自定义 Token
@Injectable()
export class AppService {
  constructor(
    @Inject("CONFIG") private config: any,
    @Inject("LOGGER") private logger: Logger
  ) {}
}
```

### Q6: 全局模块、动态模块和循环依赖怎么处理？

```typescript
// 1. 全局模块 — @Global() 装饰，无需在每个模块 imports 中声明
@Global()
@Module({
  providers: [PrismaService],
  exports: [PrismaService],
})
export class PrismaModule {}

// 2. 动态模块 — 运行时传入配置
@Module({})
export class DatabaseModule {
  static forRoot(options: DbOptions): DynamicModule {
    return {
      module: DatabaseModule,
      providers: [
        { provide: "DB_OPTIONS", useValue: options },
        { provide: "CONNECTION", useFactory: () => createConnection(options) },
      ],
      exports: ["CONNECTION"],
    }
  }
}

// 使用
@Module({ imports: [DatabaseModule.forRoot({ host: "localhost", port: 5432 })] })
// 3. 循环依赖 — forwardRef() 延迟解析
@Module({
  imports: [forwardRef(() => UserModule)],
  exports: [AuthService],
})
export class AuthModule {}
```

## 路由与请求处理

### Q7: Controller 如何获取请求参数？

```typescript
@Controller("users")
export class UserController {
  // 路由参数
  @Get(":id")
  getUser(@Param("id") id: string) {}

  // 查询参数 — GET /users?page=1&limit=10
  @Get()
  list(@Query() query: { page: number; limit: number }) {}

  // 请求体
  @Post()
  create(@Body() dto: CreateUserDto) {}

  // 请求头
  @Get()
  getUser(@Headers("authorization") auth: string) {}

  // IP / Host
  @Get()
  info(@Req() req: Request, @Ip() ip: string) {}

  // 响应对象
  @Get()
  custom(@Res() res: Response) {
    res.status(200).json({ data: "custom" })
  }
}
```

### Q8: DTO 和 ValidationPipe 如何配合使用？

```typescript
// 安装: npm install class-validator class-transformer

// DTO 定义
import { IsString, IsEmail, MinLength, IsOptional, IsEnum } from "class-validator"
import { ApiProperty } from "@nestjs/swagger"

export enum Role {
  ADMIN = "admin",
  USER = "user",
}

export class CreateUserDto {
  @ApiProperty({ description: "用户名" })
  @IsString()
  @MinLength(2)
  name: string

  @ApiProperty({ description: "邮箱" })
  @IsEmail()
  email: string

  @ApiProperty({ enum: Role, default: Role.USER })
  @IsOptional()
  @IsEnum(Role)
  role?: Role = Role.USER
}

// 全局启用校验
app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true, // 自动剔除 DTO 未定义的属性
    forbidNonWhitelisted: true, // 如果有未知属性则报错
    transform: true, // 自动转换类型（如 string→number）
  })
)
```

### Q9: 如何实现响应格式统一和分页？

```typescript
// 1. Interceptor 统一响应格式
@Injectable()
export class TransformInterceptor<T> implements NestInterceptor<T, Response<T>> {
  intercept(context: ExecutionContext, next: CallHandler): Observable<Response<T>> {
    return next.handle().pipe(
      map((data) => ({
        code: 0,
        message: "success",
        data,
        timestamp: new Date().toISOString(),
      })),
    )
  }
}

// 2. 分页 DTO
export class PaginationDto {
  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  page?: number = 1

  @IsOptional()
  @Type(() => Number)
  @IsInt()
  @Min(1)
  @Max(100)
  limit?: number = 10
}

// 分页响应
export interface PaginatedResult<T> {
  items: T[]
  total: number
  page: number
  limit: number
  totalPages: number
}

@Get()
async findAll(@Query() query: PaginationDto): Promise<PaginatedResult<User>> {
  return this.userService.findAll(query)
}
```

## 中间件与守卫

### Q10: Guard 如何实现 JWT 认证？

```typescript
// 安装: npm install @nestjs/jwt @nestjs/passport passport passport-jwt

// 1. JWT 策略
@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor() {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      secretOrKey: process.env.JWT_SECRET,
    })
  }
  async validate(payload: { sub: string; role: string }) {
    // 返回值会注入到 request.user 中
    return { id: payload.sub, role: payload.role }
  }
}

// 2. JWT Guard
@Injectable()
export class JwtAuthGuard extends AuthGuard("jwt") {}

// 3. 使用
@UseGuards(JwtAuthGuard)
@Controller("users")
export class UserController {}

// 4. 角色 Guard
@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredRoles = this.reflector.getAllAndOverride<string[]>(ROLES_KEY, [
      context.getHandler(),
      context.getClass(),
    ])
    if (!requiredRoles) return true
    const { user } = context.switchToHttp().getRequest()
    return requiredRoles.includes(user.role)
  }
}

// 装饰器: @Roles('admin')
export const Roles = (...roles: string[]) => SetMetadata(ROLES_KEY, roles)
```

### Q11: 中间件和拦截器的区别是什么？

| 维度         | Middleware            | Interceptor                  |
| ------------ | --------------------- | ---------------------------- |
| 时机         | 路由匹配之前          | 路由执行前后                 |
| 访问路由信息 | ❌ 不知道具体路由     | ✅ 可获取 Controller/Handler |
| 修改响应     | ❌                    | ✅ 通过 `map()` 包装返回值   |
| 适用场景     | 日志/CORS/body-parser | 响应格式化/缓存/耗时统计     |

## 数据库与 ORM

### Q12: NestJS 如何集成 TypeORM 和 Prisma？

```typescript
// ===== TypeORM =====
// @nestjs/typeorm
@Module({
  imports: [
    TypeOrmModule.forRoot({
      type: "postgres",
      host: "localhost",
      port: 5432,
      username: "postgres",
      password: "postgres",
      database: "mydb",
      entities: [User],
      synchronize: process.env.NODE_ENV !== "production", // ⚠️ 生产关掉
    }),
    TypeOrmModule.forFeature([User]), // 注册实体 → 注入 Repository
  ],
})
export class AppModule {}

@Injectable()
export class UserService {
  constructor(
    @InjectRepository(User)
    private userRepo: Repository<User>
  ) {}

  findAll(): Promise<User[]> {
    return this.userRepo.find({ where: { isActive: true } })
  }
}

// ===== Prisma =====
@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit {
  async onModuleInit() {
    await this.$connect()
  }
  async onModuleDestroy() {
    await this.$disconnect()
  }
}

@Injectable()
export class UserService {
  constructor(private prisma: PrismaService) {}
  findAll() {
    return this.prisma.user.findMany({ where: { isActive: true } })
  }
}
```

### Q14: 如何实现文件上传和静态文件服务？

```typescript
// 文件上传
import { FileInterceptor } from "@nestjs/platform-express"
import { diskStorage } from "multer"

@Post("upload")
@UseInterceptors(
  FileInterceptor("file", {
    storage: diskStorage({
      destination: "./uploads",
      filename: (req, file, cb) => {
        const uniqueSuffix = Date.now() + "-" + Math.round(Math.random() * 1e9)
        cb(null, file.fieldname + "-" + uniqueSuffix + extname(file.originalname))
      },
    }),
    limits: { fileSize: 5 * 1024 * 1024 }, // 5MB
    fileFilter: (req, file, cb) => {
      if (!file.mimetype.match(/\/(jpg|jpeg|png|gif)$/)) {
        cb(new BadRequestException("仅支持图片"), false)
      }
      cb(null, true)
    },
  }),
)
uploadFile(@UploadedFile() file: Express.Multer.File) {
  return { url: `/uploads/${file.filename}` }
}

// 多文件
@Post("uploads")
@UseInterceptors(FilesInterceptor("files", 5))
uploadFiles(@UploadedFiles() files: Express.Multer.File[]) {}
```

### Q15: 如何配置 CORS 和 Helmet 安全头？

```typescript
async function bootstrap() {
  const app = await NestFactory.create(AppModule)

  // CORS
  app.enableCors({
    origin: process.env.ALLOWED_ORIGINS?.split(",") || "http://localhost:3000",
    credentials: true,
    methods: "GET,POST,PUT,DELETE,PATCH",
  })

  // Helmet 安全头
  app.use(helmet())

  // CSRF
  app.use(csurf())

  // 限流
  app.use(
    rateLimit({
      windowMs: 60 * 1000, // 1 分钟
      max: 100, // 最多 100 次
    })
  )

  // 全局前缀
  app.setGlobalPrefix("api/v1")

  await app.listen(3000)
}
```

### 装饰器速查

| 装饰器                                                     | 说明                   |
| ---------------------------------------------------------- | ---------------------- |
| `@Module()`                                                | 定义模块               |
| `@Controller("path")`                                      | 定义控制器（路由前缀） |
| `@Injectable()`                                            | 标记可注入的服务       |
| `@Get()` / `@Post()` / `@Put()` / `@Delete()` / `@Patch()` | HTTP 方法              |
| `@Param("key")`                                            | 路由参数               |
| `@Query()`                                                 | 查询参数               |
| `@Body()`                                                  | 请求体                 |
| `@Headers("key")`                                          | 请求头                 |
| `@Req()`                                                   | 原生 Request 对象      |
| `@Res()`                                                   | 原生 Response 对象     |
| `@Inject(token)`                                           | 注入自定义 token       |
| `@Optional()`                                              | 可选注入               |
| `@UseGuards()`                                             | 守卫                   |
| `@UseInterceptors()`                                       | 拦截器                 |
| `@UsePipes()`                                              | 管道                   |
| `@Cron()`                                                  | 定时任务               |
| `@Global()`                                                | 全局模块               |

### 生命周期速查

```
请求 → Middleware → Guard → Interceptor(before) → Pipe → Controller → Service → Interceptor(after) → ExceptionFilter → 响应
```
