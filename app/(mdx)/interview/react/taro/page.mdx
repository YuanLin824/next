## 一、基础概念

### Q1: 什么是 Taro？它的核心设计理念是什么？

Taro 是京东凹凸实验室开源的**跨端开发框架**，一套代码编译到多个平台。

| 能力           | 说明                                                      |
| -------------- | --------------------------------------------------------- |
| **跨端编译**   | 微信/支付宝/百度/字节/QQ/京东小程序 + H5 + React Native   |
| **多框架支持** | React / Vue 3 / Vue 2 / Nerv（类 React）                  |
| **一致的 API** | 统一 `Taro.*` API（`Taro.request`、`Taro.navigateTo` 等） |
| **组件化**     | 内置 View/Text/Image/ScrollView 等跨端组件                |
| **CSS 预处理** | 支持 Sass/Less/Stylus + Tailwind CSS（通过插件）          |

### Q2: Taro 的编译原理是什么？

```
源码（React/Vue 组件）
    ↓ Babel / SWC 转译
Taro 中间代码（抽象语法树 AST）
    ↓ 各平台插件处理
目标平台代码（WXML/WXSS/JS → 小程序 / HTML/CSS/JS → H5）
```

关键步骤：

1. **模板编译**：React/Vue 的 JSX → 小程序 WXML 模板
2. **样式编译**：CSS/Sass → WXSS（小程序）/ CSS（H5）
3. **运行时**：Taro Runtime 在目标平台上模拟 React/Vue 生命周期

### Q3: Taro 和 uni-app 有什么区别？

| 维度       | Taro                  | uni-app             |
| ---------- | --------------------- | ------------------- |
| 框架支持   | React + Vue 3 + Vue 2 | Vue 为主            |
| 开发体验   | 类 React DSL          | Vue DSL             |
| 跨端范围   | 6 小程序 + H5 + RN    | 多小程序 + App + H5 |
| 社区生态   | React 生态            | Vue 生态            |
| TypeScript | 原生支持              | 支持                |
| 编译方式   | 模板编译 + 运行时     | 编译时模板转换      |
| 学\*曲线   | React 开发者友好      | Vue 开发者友好      |
| 公司       | 京东                  | DCloud              |

## 二、项目配置与 CLI

### Q4: Taro 如何创建和配置项目？

```bash
# 安装 CLI
npm install -g @tarojs/cli

# 创建项目
taro init myApp
# 交互式选择: 框架(React/Vue) + CSS 预处理器 + 模板

# 快速创建 React + TypeScript 项目
npx @tarojs/cli init myApp --template react-ts

# 启动
npm run dev:weapp   # 微信小程序
npm run dev:h5       # H5
npm run dev:alipay   # 支付宝小程序
npm run dev:swan     # 百度小程序
npm run dev:tt       # 字节小程序
npm run dev:qq       # QQ 小程序
npm run dev:jd       # 京东小程序
npm run dev:rn       # React Native

# 构建
taro build --type weapp --watch
```

```tsx
// #ifndef H5
console.log("除了 H5 外的所有平台都编译")
```

## 四、路由与导航

### Q10: Taro 的路由系统和导航 API？

```ts
import Taro from "@tarojs/taro"

// 跳转到非 TabBar 页面 → 保留当前页
Taro.navigateTo({ url: "/pages/detail/detail?id=123" })

// 跳转到 TabBar 页面 → 关闭所有非 TabBar 页面
Taro.switchTab({ url: "/pages/index/index" })

// 关闭当前页，跳转到新页
Taro.redirectTo({ url: "/pages/login/login" })

// 关闭所有页面，打开新页
Taro.reLaunch({ url: "/pages/index/index" })

// 返回
Taro.navigateBack({ delta: 1 })

// 获取当前页面实例
const pages = Taro.getCurrentPages()
const current = pages[pages.length - 1]
console.log(current.route) // 当前页面路径
console.log(current.options) // 页面参数
```

```tsx
// 路由传参与接收

Taro.navigateTo({ url: "/pages/detail/detail?id=123&name=Alice" })

// React Hooks 方式
const router = useRouter()

// Class 组件方式
componentDidMount() {
  const { router } = getCurrentInstance()
  console.log(router.params)
}
```

### Q15: 小程序中的全局数据和页面间如何通信？

```ts
// ===== 方式 1: getApp() =====

  globalData = { user: null }

// 任意页面
```

### Q17: 小程序的分包策略怎么设计？

```ts
// app.config.ts
export default {
  pages: [
    "pages/index/index", // 主包 — 首页 + 核心页
    "pages/cart/cart",
  ],
  subPackages: [
    {
      root: "packageUser",
      pages: ["pages/login/login", "pages/register/register", "pages/settings/settings"],
    },
    {
      root: "packageOrder",

  },
```

| 策略       | 说明                                        |
| ---------- | ------------------------------------------- |
| 主包 ≤ 2MB | 只放首页和公共组件                          |
| 分包按功能 | user/order/product 各一个                   |

| 预加载     | 高频路径提前下载                            |

## 八、Hooks 与自定义 Hook

### Q18: Taro 提供了哪些实用的 Hooks？

```tsx
import {
  useRouter, // 获取路由信息（params/path/等）
  useDidShow, // 页面显示时执行（onShow）
  useDidHide, // 页面隐藏
  useReady, // 页面初次渲染完成（onReady）
  usePullDownRefresh, // 下拉刷新回调
  useReachBottom, // 触底回调
  usePageScroll, // 页面滚动
  useShareAppMessage, // 分享（分享给好友）
  useShareTimeline, // 分享到朋友圈
  useTabItemTap, // 点击 Tab Bar
  useLoad, // 页面加载（onLoad）
  useUnload, // 页面卸载
  useResize, // Canvas 尺寸变化 / 屏幕旋转
  useAddToFavorites, // 收藏
  useOptionMenuClick, // 标题栏按钮点击
} from "@tarojs/taro"

// 使用
function Index() {
  useDidShow(() => {
    console.log("页面显示了")
  })

  usePullDownRefresh(() => {
    refreshData().then(() => Taro.stopPullDownRefresh())
  })

  useReachBottom(() => {
    loadMore()
  })

  return <View>内容</View>
}
```

### Q19: useDidShow 和 useEffect 的区别？useDidShow 什么时候执行？

| Hook                       | 触发时机                                                 | 适用场景           |
| -------------------------- | -------------------------------------------------------- | ------------------ |
| `useDidShow`               | 页面显示（onShow）：首次进入、从后台切回、从其他页面返回 | 刷新数据、重置状态 |
| `useEffect(()=>{}, [])`    | 组件挂载一次                                             | 初始化逻辑         |
| `useEffect(()=>{}, [dep])` | 组件挂载 + dep 变化                                      | 响应数据变化       |
| `useReady`                 | 页面初次渲染完成（onReady）                              | DOM 就绪后的操作   |
| `useLoad`                  | 页面加载时（onLoad），只一次                             | 获取路由参数       |

```tsx
// 典型场景
useLoad((options) => {
  // 获取路由参数
  const id = options.id
  getDetail(id)
})

useDidShow(() => {
  // 每次进入页面都刷新 — 比如回到列表页看到新增的数据
  refreshList()
})
```

### Q25: 如何实现一个完整的分页列表？

```tsx
function PagedList() {
  const [list, setList] = useState([])
  const [page, setPage] = useState(1)
  const [loading, setLoading] = useState(false)
  const [hasMore, setHasMore] = useState(true)

  const fetchData = useCallback(async () => {
    if (loading || !hasMore) return
    setLoading(true)
    try {
      const res = await Taro.request({ url: "/api/list", data: { page, size: 20 } })
      const newList = res.data.items
      setList((prev) => (page === 1 ? newList : [...prev, ...newList]))
      setHasMore(newList.length === 20)
      setLoading(false)
    } catch {
      setLoading(false)
    }
  }, [page, loading, hasMore])

  useEffect(() => {
    fetchData()
  }, [page])

  usePullDownRefresh(async () => {
    setPage(1)
    setHasMore(true)
    await fetchData()
    Taro.stopPullDownRefresh()
  })

  useReachBottom(() => {
    if (!loading && hasMore) setPage((p) => p + 1)
  })

  return (
    <ScrollView scrollY style={{ height: "100vh" }}>
      {list.map((item) => (
        <Item key={item.id} data={item} />
      ))}
      {loading && <View className="loading">加载中...</View>}
      {!hasMore && <View className="no-more">没有更多了</View>}
    </ScrollView>
  )
}
```

### Q27: 完整的登录 + Token 管理流程？

```ts
// services/auth.ts
let refreshing = false
let pendingRequests: Array<(token: string) => void> = []

function getToken() {
  return Taro.getStorageSync("token")
}
function setToken(t: string) {
  Taro.setStorageSync("token", t)
}

// 登录
async function login() {
  try {
    const { code } = await Taro.login()
    const res = await Taro.request({ url: "/api/login", method: "POST", data: { code } })
    setToken(res.data.token)
    return res.data.token
  } catch (err) {
    Taro.showToast({ title: "登录失败", icon: "error" })
    throw err
  }
}

// 请求拦截（Token 过期自动刷新）
async function request(url: string, options: any = {}) {
  const token = getToken()
  if (token) {
    options.header = { ...options.header, Authorization: `Bearer ${token}` }
  }

  try {
    const res = await Taro.request({ url, ...options })
    return res.data
  } catch (err) {
    if (err.statusCode === 401) {
      if (!refreshing) {
        refreshing = true
        const newToken = await login()
        refreshing = false
        pendingRequests.forEach((fn) => fn(newToken))
        pendingRequests = []
        return request(url, options) // 用新 token 重试
      }
      return new Promise((resolve) => {
        pendingRequests.push((newToken) => {
          options.header.Authorization = `Bearer ${newToken}`
          resolve(request(url, options))
        })
      })
    }
    throw err
  }
}

// 页面中静默登录
function useLogin() {
  useDidShow(async () => {
    try {
      await Taro.checkSession()
    } catch {
      await login()
    }
  })
}
```

### Q37: Taro 中如何做拦截器封装（类似 Axios 拦截器）？

```ts
// services/request.ts
type Options = Taro.request.Option

class Request {
  // 请求拦截器队列
  private reqInterceptors: Array<(config: Options) => Options> = []
  // 响应拦截器队列
  private resInterceptors: Array<(res: any) => any> = []

  // 注册请求拦截器
  useReqInterceptor(fn: (config: Options) => Options) {
    this.reqInterceptors.push(fn)
  }

  // 注册响应拦截器
  useResInterceptor(fn: (res: any) => any) {
    this.resInterceptors.push(fn)
  }

  async request(options: Options) {
    // 执行请求拦截器
    for (const interceptor of this.reqInterceptors) {
      options = interceptor(options)
    }

    try {
      const res = await Taro.request(options)

      // 执行响应拦截器
      let data = res.data
      for (const interceptor of this.resInterceptors) {
        data = interceptor(data)
      }

      return data
    } catch (err) {
      // 统一错误处理
      const { statusCode } = err
      switch (statusCode) {
        case 401:
          /* 未登录 */ break
        case 403:
          Taro.showToast({ title: "无权限", icon: "error" })
          break
        case 500:
          Taro.showToast({ title: "服务器错误", icon: "error" })
          break
        default:
          Taro.showToast({ title: "网络异常", icon: "error" })
      }
      throw err
    }
  }

  get(url: string, data?: any) {
    return this.request({ url, method: "GET", data })
  }
  post(url: string, data?: any) {
    return this.request({ url, method: "POST", data })
  }
}

export const request = new Request()

// 使用
request.useReqInterceptor((config) => {
  const token = Taro.getStorageSync("token")
  if (token) config.header = { ...config.header, Authorization: `Bearer ${token}` }
  return config
})

request.get("/api/users", { page: 1 })
```

## 十八、面试速查

### Q40: 一句话总结 Taro 的核心价值？

**一套 React/Vue 代码 → 编译成 6+ 平台代码**，开发者只写一次，框架负责平台适配（组件 + API + 样式）。

### Q41: Taro 和 Remax 有什么不同？

| 维度         | Taro                   | Remax                          |
| ------------ | ---------------------- | ------------------------------ |
| 原理         | 编译时转换（模板编译） | 运行时方案（React Reconciler） |
| 性能         | 接近原生               | 稍低（多一层运行时）           |
| React 兼容性 | 部分限制               | 完全兼容（真正的 React）       |
| 小程序支持   | 6 小程序 + H5 + RN     | 微信/支付宝/字节               |
| 社区         | 大                     | 小                             |

### Q42: 如何在 Taro 项目中做主题切换？

```tsx
// 1. CSS 变量
// app.scss
page { --bg: #fff; --text: #333; }
page[data-theme="dark"] { --bg: #1a1a1a; --text: #eee; }

// 2. 切换
Taro.setStorageSync("theme", "dark")
document.documentElement.setAttribute("data-theme", "dark") // H5 端

// 3. 组件中使用
<View style={{ backgroundColor: "var(--bg)", color: "var(--text)" }} />
```

## 补充速查表

### e.target vs e.currentTarget（小程序事件对象）

| 属性              | 说明                                             |
| ----------------- | ------------------------------------------------ |
| `e.target`        | 触发事件的**源头元素**（点击了哪个组件）         |
| `e.currentTarget` | 绑定事件的**当前元素**（事件在哪个组件上绑定的） |
| `e.detail`        | 额外信息（如 input 的 value）                    |
| `e.type`          | 事件类型 (tap / longpress)                       |
| `e.timeStamp`     | 事件时间戳                                       |

### 常见小程序限制

| 限制          | 具体                    |
| ------------- | ----------------------- |
| 包大小        | 主包 ≤ 2MB，总包 ≤ 20MB |
| 页面栈        | 最多 10 层              |
| WXS/WXML      | 不直接支持 ES6+、import |
| 并发请求      | 最多 10 个 wx.request   |
| 本地存储      | 10MB                    |
| setData 单次  | ≤ 256KB                 |
| 自定义 TabBar | 每个 Tab 页需独立配置   |
