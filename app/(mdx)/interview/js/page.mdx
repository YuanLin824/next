## 一、基础概念（难度：★☆☆）

### Q1: JS 有哪些数据类型？如何判断？

**8 种数据类型**：

```
基本类型（7 种，存栈上，值不可变）：
string  number  boolean  null  undefined  symbol  bigint

引用类型（1 种，存堆上，按引用访问）：
object（含 array、function、date、regexp、map、set 等）

注意：typeof null === "object"（历史遗留 bug，null 的前 3 位二进制位是 000）
```

**类型判断方法对比**：

| 方法                               | 适用场景                          | 局限                                       |
| ---------------------------------- | --------------------------------- | ------------------------------------------ |
| `typeof`                           | 基本类型快速判断                  | `null` 返回 "object"；对象无法区分具体类型 |
| `instanceof`                       | 判断对象是否属于某类              | 跨 iframe/跨 realm 失效；基本类型需包装    |
| `Object.prototype.toString.call()` | **终极方案**，返回 `[object Xxx]` | 需 `Symbol.toStringTag` 干扰防护           |
| `Array.isArray()`                  | 专门判断数组                      | 仅数组                                     |

```js
// 万能类型判断
function getType(value) {
  return Object.prototype.toString.call(value).slice(8, -1)
}
getType([]) // "Array"
getType(null) // "Null"
getType(new Date()) // "Date"
getType(/x/) // "RegExp"
```

### Q2: `null` 和 `undefined` 的区别？

| 对比项   | `null`                                                        | `undefined`                                               |
| -------- | ------------------------------------------------------------- | --------------------------------------------------------- |
| 语义     | **有值但为空**（显式设置）                                    | **未定义**（变量声明未赋值）                              |
| 产生场景 | 手动设置、`JSON.parse` 中不存在返回 null、DOM 找不到返回 null | 变量未赋值、函数无 return、访问对象不存在的属性、形参未传 |
| typeof   | `"object"`（bug）                                             | `"undefined"`                                             |
| 转换     | `Number(null) === 0`                                          | `Number(undefined) === NaN`                               |
| 相等     | `null == undefined → true`                                    | 同上                                                      |

```js
// 规范场景
let a // undefined（声明未赋值）
const b = null // 显式空值
function fn(x) {} // 不传参时 x === undefined

// 判空技巧：只判断 null/undefined
value == null // 等价于 value === null || value === undefined
// 使用 ?? 提供默认值
const name = user?.name ?? "游客"
```

### Q3: `==` 和 `===` 的区别？`==` 的隐式转换规则？

```js
=== 严格相等：类型不同直接 false，不做转换
== 宽松相等：类型不同时先隐式转换再比较
```

**`==` 的转换规则**（高频考点）：

```
1. null == undefined → true（特殊规则）
2. 数字 vs 字符串 → 字符串转数字："5" == 5 → true
3. 布尔 vs 其他 → 布尔先转数字：true == 1 → true
4. 对象 vs 基本类型 → 对象调 ToPrimitive（valueOf → toString）
5. 两个对象 → 比较引用地址（必须同一引用才 true）
```

```js
// 经典题目
[] == ![] // ? → true（[] 转 ""，![] 转 false → 0，"" == 0 → true）
[] == 0 // true（"" → 0）
![] == 0 // true（![] → false → 0）
[1] == 1 // true（[1].toString() → "1" → 1）
[1, 2] == "1,2" // true
null == 0 // false（null 只与 undefined 相等）
NaN == NaN // false（NaN 与任何值都不相等）
```

### Q5: `var` / `let` / `const` 的区别？

| 对比项   | `var`                | `let`             | `const`              |
| -------- | -------------------- | ----------------- | -------------------- |
| 作用域   | 函数作用域           | **块级作用域**    | 块级作用域           |
| 变量提升 | ✅ 提升（undefined） | ✅ 提升但 **TDZ** | ✅ 提升但 **TDZ**    |
| 重复声明 | ✅ 允许              | ❌ 报错           | ❌ 报错              |
| 重新赋值 | ✅                   | ✅                | ❌（对象属性可变！） |
| 全局声明 | 挂到 window          | 不挂 window       | 不挂 window          |
| 循环陷阱 | for 循环 i 共享      | 每次迭代新绑定    | -                    |

```js
// TDZ（暂时性死区）：声明前访问报错
console.log(a) // ❌ ReferenceError: Cannot access 'a' before initialization
let a = 1

// const 的本质：绑定不可变，不是值不可变
const obj = { name: "a" }
obj.name = "b" // ✅ 允许（对象内容可变）
obj = {} // ❌ 报错（重新绑定不允许）
```

**var 经典循环陷阱**：

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0) // 3 3 3（共享 i）
}
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0) // 0 1 2（每次迭代新绑定）
}
```

### Q6: 变量提升（Hoisting）的规则？

```js
// 1. var 声明提升到作用域顶部，初始化为 undefined
console.log(a) // undefined（不报错）
var a = 1

// 2. 函数声明整体提升（可先调用）
foo() // ✅ 正常执行

  console.log("hi")
}

// 3. 函数表达式不提升（只提升 var）
bar() // ❌ TypeError: bar is not a function

// 实际解析为：var bar = undefined（此时调用 undefined 报类型错误）

// 4. 提升顺序：函数声明 > var 声明（同名时函数覆盖 var）
```

## 二、作用域与闭包（难度：★★☆）

### Q7: 什么是作用域链？作用域查找规则？

```
作用域类型：全局作用域 / 函数作用域 / 块级作用域（let/const）

作用域链：由内到外的词法作用域链（静态作用域，定义时决定，非调用时）
```

```js
var a = 1
function outer() {
  var b = 2
  function inner() {
    var c = 3
    console.log(a + b + c) // 6：inner → outer → global 逐层查找
  }
  inner()
}
outer()

// 关键点：作用域在「定义时」确定（词法作用域）
var name = "global"
function show() {
  console.log(name)
}
function wrapper() {
  var name = "local"
  show() // 输出 "global"！show 定义在全局，链指向全局
}
```

### Q8: 什么是闭包？应用场景？内存问题？

**闭包**：函数 + 其定义时所在词法作用域的引用。内部函数持有外部函数变量的引用，即使外部函数已返回。

```js
function counter() {
  let count = 0
  return function () {
    return ++count // 闭包：持有 count 的引用
  }
}
const add = counter()
add() // 1
add() // 2（count 没有随 counter 销毁）

// 本质：内部函数被外部引用，其作用域链上的变量无法被 GC 回收
```

**应用场景**：

```js
// 1. 私有变量（模块模式）
const module = (() => {
  let privateData = 0
  return { get: () => privateData, set: (v) => (privateData = v) }
})()

// 2. 缓存/记忆化
function memoize(fn) {
  const cache = {}
  return function (...args) {
    const key = JSON.stringify(args)
    return cache[key] ?? (cache[key] = fn(...args))
  }
}

// 3. 循环事件绑定（var 场景）
for (var i = 0; i < 3; i++) {
  btns[i].onclick = (function (n) {
    return () => console.log(n)
  })(i)
}

// 4. 防抖节流、柯里化、单例
```

**内存问题**：闭包引用的变量不释放 → 内存泄漏风险。**解决**：用完后置 `null` 断开引用，或用 WeakMap 存储。

### Q9: `this` 的指向规则（4 种绑定）？

```
this 指向规则（按优先级从高到低）：

1. new 绑定：new Foo() → this = 新对象
2. 显式绑定：call/apply/bind → this = 传入的第一个参数
3. 隐式绑定：obj.fn() → this = obj
4. 默认绑定：独立调用 fn() → 非严格模式 this = window/global，严格模式 undefined

补充：箭头函数没有自己的 this，捕获定义时外层 this（不可被 call/bind 改变）
```

```js
// 经典题目
function foo() {
  console.log(this)
}
foo() // window（默认绑定）

const obj = { name: "obj", foo }
obj.foo() // obj（隐式绑定）

const fn = obj.foo
fn() // window（隐式绑定丢失！独立调用）

foo.call(obj) // obj（显式绑定）

const obj2 = {
  name: "obj2",
  arrow: () => console.log(this.name), // 箭头函数：捕获定义时 this
  normal() {
    console.log(this.name)
  },
}
obj2.arrow() // undefined（箭头函数 this 是全局）
obj2.normal() // obj2
```

**隐式绑定丢失的经典场景**：

```js
const user = {
  name: "Alice",
  greet() {
    console.log(this.name)
  },
}
setTimeout(user.greet, 100) // undefined！回调中 this 丢失
// 解决：user.greet.bind(user) 或 () => user.greet()
```

### Q10: `call` / `apply` / `bind` 的区别？

| 方法    | 参数形式                            | 立即执行 | 返回       | 场景               |
| ------- | ----------------------------------- | -------- | ---------- | ------------------ |
| `call`  | 逐个传参 `fn.call(ctx, a, b)`       | ✅       | 函数结果   | 参数少             |
| `apply` | 数组传参 `fn.apply(ctx, [a, b])`    | ✅       | 函数结果   | 参数是数组/类数组  |
| `bind`  | 逐参（可两次传参）`fn.bind(ctx, a)` | ❌       | **新函数** | 预设 this + 偏函数 |

```js
// 典型应用
Math.max.apply(null, [1, 5, 3]) // 5（数组取最大）
Math.max(...[1, 5, 3]) // 5（现代写法）

Array.prototype.slice.call(arguments) // 类数组转真数组
Array.from(arguments) // 现代写法

// bind 偏函数
function add(a, b) {
  return a + b
}
const add5 = add.bind(null, 5) // 预设第一个参数
add5(3) // 8
```

### Q11: 箭头函数与普通函数的区别？

| 对比项                | 普通函数                 | 箭头函数                    |
| --------------------- | ------------------------ | --------------------------- |
| `this`                | 调用时动态决定           | **定义时捕获**（词法 this） |
| `arguments`           | ✅ 有                    | ❌ 没有（用 rest 替代）     |
| `new` 调用            | ✅ 可以                  | ❌ 不可（无 prototype）     |
| `prototype`           | ✅ 有                    | ❌ 没有                     |
| `call/bind` 改变 this | ✅                       | ❌ 无效                     |
| 适用                  | 需要动态 this / 构造函数 | 回调、闭包、函数式          |

```js
// 箭头函数不能作为构造函数的陷阱
const Foo = () => {}
new Foo() // ❌ TypeError: Foo is not a constructor

// 箭头函数适合作回调
const obj = {
  count: 0,
  start() {
    setInterval(() => this.count++, 1000) // ✅ this 是 obj
    // setInterval(function () { this.count++ }, 1000) // ❌ this 是 window
  },
}
```

## 三、原型与继承（难度：★★☆）

### Q12: 原型与原型链？`__proto__` 和 `prototype` 的区别？

```
prototype：函数特有的属性（构造函数的原型对象）
__proto__：所有对象都有的内部属性（[[Prototype]]），指向构造函数的 prototype

实例.__proto__ === 构造函数.prototype
构造函数.prototype.constructor === 构造函数
```

```js
function Person(name) {
  this.name = name
}
Person.prototype.sayHi = function () { console.log("hi " + this.name) }

const p = new Person("Tom")
p.sayHi() // hi Tom（实例方法找不到 → 沿原型链找到 Person.prototype）

// 原型链查找：
p.sayHi → p.__proto__（Person.prototype）→ p.__proto__.__proto__（Object.prototype）→ null
```

```
原型链图：

p (实例)
 ├─ __proto__ → Person.prototype（函数原型）
 │                ├─ __proto__ → Object.prototype（所有对象的祖先）
 │                │                └─ __proto__ → null（尽头）
 │                └─ constructor → Person
 └─ 属性 name
```

**判断关系的方法**：

```js
p instanceof Person // true：沿 p 的原型链找 Person.prototype
Person.prototype.isPrototypeOf(p) // true（更规范）
p instanceof Object // true（原型链上最终都有 Object.prototype）
```

### Q13: `new` 的过程发生了什么？

```js
// new Foo() 的 4 个步骤
function myNew(Constructor, ...args) {
  // 1. 创建空对象，原型指向构造函数的 prototype
  const obj = Object.create(Constructor.prototype)
  // 2. 执行构造函数，this 绑定到新对象
  const result = Constructor.apply(obj, args)
  // 3. 判断返回值：返回对象则用它，否则返回新对象
  return result instanceof Object ? result : obj
  // 4. （隐含）构造函数中没有显式 return 对象时，自动返回新对象
}

// 使用
const p = myNew(Person, "Tom")
p instanceof Person // true
```

### Q14: 继承有哪些方式？各有什么优缺点？

```js
// 方式 1：原型链继承（子原型 = 父实例）
function Child() {}
Child.prototype = new Parent()
// 缺点：引用类型属性被共享；无法向父构造函数传参

// 方式 2：构造函数继承（call 父）
function Child(name) {
  Parent.call(this, name) // 复制父实例属性到子实例
}
// 缺点：方法都在构造函数里，无法复用

// 方式 3：组合继承（推荐旧方案）
function Child(name) {
  Parent.call(this, name)
}
Child.prototype = new Parent() // 父方法可复用
// 缺点：父构造函数被调用两次

// 方式 4：寄生组合式继承（最优经典方案）
Child.prototype = Object.create(Parent.prototype)
Child.prototype.constructor = Child
// 优点：只继承原型，不重复执行父构造函数

// 方式 5：ES6 class（现代推荐）
class Child extends Parent {
  constructor(name) {
    super(name) // 必须先调用 super 才能用 this
  }
}
```

**继承方式对比表**：

| 方式          | 父构造执行次数 | 引用属性共享问题 | 可传参 | 推荐度   |
| ------------- | -------------- | ---------------- | ------ | -------- |
| 原型链        | 1              | ✅ 有            | ❌     | 低       |
| 构造函数      | 1（每实例）    | ❌ 无            | ✅     | 低       |
| 组合          | 2              | ❌ 无            | ✅     | 中       |
| 寄生组合式    | 1              | ❌ 无            | ✅     | **高**   |
| class extends | 1              | ❌ 无            | ✅     | **最高** |

### Q15: `instanceof` 的原理？如何手写？

```js
// 原理：沿左侧对象的原型链查找，是否能找到右侧构造函数的 prototype
function myInstanceof(left, right) {
  let proto = Object.getPrototypeOf(left) // left.__proto__
  const prototype = right.prototype
  while (proto) {
    if (proto === prototype) return true
    proto = Object.getPrototypeOf(proto) // 沿链上溯
  }
  return false
}

myInstanceof([], Array) // true
myInstanceof([], Object) // true
myInstanceof("str", String) // false（基本类型没有原型链）
// 注意：Symbol.hasInstance 可定制 instanceof 行为
```

## 四、数组与对象（难度：★★☆）

### Q16: 数组方法分类（会/不会修改原数组）？

| 类别           | 方法                                                           | 返回值           |
| -------------- | -------------------------------------------------------------- | ---------------- |
| **修改原数组** | `push pop shift unshift splice sort reverse fill`              | 长度/元素/数组   |
| **不修改**     | `concat slice join indexOf lastIndexOf includes`               | 新数组/索引/布尔 |
| **遍历**       | `forEach map filter reduce find findIndex some every`          | 各不相同         |
| **ES6+**       | `flat flatMap at findLast with toSorted toReversed`（copy 版） | 新数组           |

```js
// 易混淆点
const arr = [1, 2, 3]
arr.map((x) => x * 2) // [2,4,6]（不修改）
arr.forEach((x) => x * 2) // undefined（只是遍历）

// 删除元素对比
arr.splice(1, 1) // 修改原数组，删除 index 1
delete arr[1] // 留下空位（length 不变，变稀疏数组）
arr.filter((x) => x !== 2) // 不修改，返回新数组

// reduce 万能
arr.reduce((acc, cur) => acc + cur, 0) // 求和
arr.reduce((acc, cur) => ({ ...acc, [cur]: cur }), {}) // 数组 → 对象
```

### Q17: 数组去重有哪些方法？（手写高频）

```js
const arr = [1, 2, 2, 3, 3, 4]

// 方案 1：Set（最简洁）
[...new Set(arr)]

// 方案 2：filter + indexOf
arr.filter((v, i) => arr.indexOf(v) === i)

const seen = {}

// 对象数组去重（按属性）
const users = [{ id: 1 }, { id: 1 }, { id: 2 }]
const unique = [...new Map(users.map(u => [u.id, u])).values()]

// 复杂值去重（JSON 序列化）
arr.filter((v, i) => arr.findIndex(x => JSON.stringify(x) === JSON.stringify(v)) === i)
```

### Q18: 数组扁平化有哪些方法？

```js
const arr = [1, [2, [3, [4]]]]

// 方案 1：flat（ES2019）
arr.flat(Infinity) // [1,2,3,4]

// 方案 2：递归
function flatten(arr, depth = Infinity) {
  return arr.flatMap((v) => (Array.isArray(v) && depth > 0 ? flatten(v, depth - 1) : [v]))
}

// 方案 3：reduce 递归
function flattenReduce(arr) {
  return arr.reduce((acc, v) => acc.concat(Array.isArray(v) ? flattenReduce(v) : v), [])
}

// 方案 4：toString 技巧（仅数字数组）
arr.toString().split(",").map(Number)

// 方案 5：迭代 + 栈（不递归，防爆栈）
function flattenIter(arr) {
  const stack = [...arr]
  const result = []
  while (stack.length) {
    const top = stack.pop()
    if (Array.isArray(top)) stack.push(...top)
    else result.unshift(top)
  }
  return result
}
```

### Q19: 深拷贝与浅拷贝？如何实现深拷贝？

```js
// 浅拷贝：只复制第一层
const copy1 = { ...obj }
const copy2 = Object.assign({}, obj)
// 内层对象仍是同一引用：copy1.arr === obj.arr → true

// 深拷贝：完整复制嵌套结构
// 方案 1：JSON（简单但有局限）
const deep = JSON.parse(JSON.stringify(obj))
// 局限：undefined/function/Symbol 会被丢弃；Date 变字符串；循环引用报错；RegExp 变 {}

// 方案 2：递归手写（覆盖核心场景）
function deepClone(target, map = new WeakMap()) {
  // 基本类型 / 函数直接返回
  if (target === null || typeof target !== "object") return target
  // 循环引用：返回已克隆的
  if (map.has(target)) return map.get(target)

  // 特殊对象
  if (target instanceof Date) return new Date(target)
  if (target instanceof RegExp) return new RegExp(target)
  if (target instanceof Map) {
    const m = new Map()
    map.set(target, m)
    target.forEach((v, k) => m.set(k, deepClone(v, map)))
    return m
  }
  if (target instanceof Set) {
    const s = new Set()
    map.set(target, s)
    target.forEach((v) => s.add(deepClone(v, map)))
    return s
  }

  // 普通对象 / 数组：保留原型
  const result = Array.isArray(target) ? [] : Object.create(Object.getPrototypeOf(target))
  map.set(target, result) // 先注册再递归（处理循环引用）

  // 拷贝所有可枚举属性（含 Symbol 键）
  Reflect.ownKeys(target).forEach((key) => {
    result[key] = deepClone(target[key], map)
  })
  return result
}
```

```js
    },
  })
```

### Q28: 事件循环（Event Loop）机制？

```
JS 单线程 + 事件循环：

调用栈（Call Stack）→ 同步代码
任务队列：
├── 宏任务（macrotask）：setTimeout / setInterval / setImmediate / I/O / UI 渲染 / script 整体

4. 取出下一个宏任务，重复
```


### Q29: Node.js 事件循环与浏览器的区别？


### Q30: 手写 Promise 并发控制（限制最大并发数）？

```js
// 场景：100 个请求，每次最多并发 5 个
async function limitConcurrency(tasks, limit) {
  const results = []
  const queue = [...tasks] // 任务队列（每个是返回 Promise 的函数）
  const workers = Array.from({ length: Math.min(limit, tasks.length) }, async () => {
    while (queue.length) {
      const task = queue.shift()
      const index = tasks.length - queue.length - 1 // 记录原始索引
      results[index] = await task()
    }
  })
  await Promise.all(workers)
  return results
}
```

### Q31: 防抖（debounce）和节流（throttle）？

| 对比项   | 防抖 debounce                   | 节流 throttle                       |
| -------- | ------------------------------- | ----------------------------------- |
| 原理     | 停止触发 N 秒后才执行           | N 秒内最多执行一次                  |
| 触发时机 | 最后一次（或第一次）触发后等待  | 固定频率执行（首/尾帧）             |
| 场景     | 搜索联想、输入校验、resize 结束 | 滚动加载、拖拽、高频点击、mousemove |
| 比喻     | 电梯：人不停进来就等关门        | 水龙头：匀速滴水                    |

```js
// 防抖（立即执行版 + 延迟版）
function debounce(fn, wait = 300, immediate = false) {
  let timer = null
  return function (...args) {
    const callNow = immediate && !timer
    clearTimeout(timer)
    timer = setTimeout(() => {
      timer = null
      if (!immediate) fn.apply(this, args)
    }, wait)
    if (callNow) fn.apply(this, args)
  }
}

// 节流（时间戳版：首次立即执行）
function throttle(fn, interval = 300) {
  let last = 0
  return function (...args) {
    const now = Date.now()
    if (now - last >= interval) {
      last = now
      fn.apply(this, args)
    }
  }
}

// 节流（定时器版：尾触发）
function throttleTimer(fn, interval = 300) {
  let timer = null
  return function (...args) {
    if (timer) return
    timer = setTimeout(() => {
      fn.apply(this, args)
      timer = null
    }, interval)
  }
}
```

### Q32: 柯里化（Currying）与偏函数？

```js
// 柯里化：把多参函数拆成单参函数链

function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args) // 参数够了，执行
    }
    return (...more) => curried(...args, ...more) // 不够则继续收集
  }
}
```

### Q37: 手写 `call` / `apply` / `bind`？

```js
// call：立即执行，逐个传参
Function.prototype.myCall = function (ctx, ...args) {
  ctx = ctx === null || ctx === undefined ? globalThis : Object(ctx) // 兜底
  const key = Symbol("fn") // 避免覆盖原有属性
  ctx[key] = this // 方法借调到目标对象
  const result = ctx[key](...args)
  delete ctx[key]
  return result
}

// apply：立即执行，数组传参
Function.prototype.myApply = function (ctx, args) {
  ctx = ctx === null || ctx === undefined ? globalThis : Object(ctx)
  const key = Symbol("fn")
  ctx[key] = this
  const result = ctx[key](...(args || []))
  delete ctx[key]
  return result
}
```

### Q40: 手写 Promise（完整版核心）？

```js
class MyPromise {
  constructor(executor) {
    this.state = "pending" // pending / fulfilled / rejected
    this.value = undefined
    this.reason = undefined
    this.onFulfilled = []
    this.onRejected = []

    const resolve = (value) => {
      if (this.state !== "pending") return
      this.state = "fulfilled"
      this.value = value
      this.onFulfilled.forEach((fn) => fn())
    }
    const reject = (reason) => {
      if (this.state !== "pending") return
      this.state = "rejected"
      this.reason = reason
      this.onRejected.forEach((fn) => fn())
    }
    try {
      executor(resolve, reject)
    } catch (err) {
      reject(err)
    }
  }

  then(onFulfilled, onRejected) {
    // 值透传
    onFulfilled = typeof onFulfilled === "function" ? onFulfilled : (v) => v
    onRejected =
      typeof onRejected === "function"
        ? onRejected
        : (e) => {
            throw e
          }

    const promise2 = new MyPromise((resolve, reject) => {
      const handle = () => {
        try {
          const result =
            this.state === "fulfilled" ? onFulfilled(this.value) : onRejected(this.reason)
          // resolvePromise：处理返回 Promise / 循环引用 / 普通值
          if (result instanceof MyPromise) {
            result.then(resolve, reject)
          } else if (result === promise2) {
            reject(new TypeError("Chaining cycle"))
          } else {
            resolve(result)
          }
        } catch (err) {
          reject(err)
        }
      }
      if (this.state === "pending") {
        this.onFulfilled.push(handle)
        this.onRejected.push(handle)
      } else {
        queueMicrotask(handle) // 异步执行
      }
    })
    return promise2
  }

  catch(onRejected) {
    return this.then(null, onRejected)
  }

  finally(callback) {
    return this.then(
      (value) => MyPromise.resolve(callback()).then(() => value),
      (reason) =>
        MyPromise.resolve(callback()).then(() => {
          throw reason
        })
    )
  }

  static resolve(value) {
    return value instanceof MyPromise ? value : new MyPromise((r) => r(value))
  }
  static reject(reason) {
    return new MyPromise((_, reject) => reject(reason))
  }
}
```

### Q41: 手写事件总线（发布订阅）？

```js
class EventBus {
  constructor() {
    this.events = new Map() // 事件名 → 回调集合
  }
  on(event, fn) {
    if (!this.events.has(event)) this.events.set(event, new Set())
    this.events.get(event).add(fn)
    return () => this.off(event, fn) // 返回取消订阅函数
  }
  once(event, fn) {
    const wrapper = (...args) => {
      this.off(event, wrapper)
      fn(...args)
    }
    this.on(event, wrapper)
  }
  emit(event, ...args) {
    this.events.get(event)?.forEach((fn) => fn(...args))
  }
  off(event, fn) {
    this.events.get(event)?.delete(fn)
    if (this.events.get(event)?.size === 0) this.events.delete(event)
  }
}

// 使用
const bus = new EventBus()
const off = bus.on("login", (user) => console.log(user))
bus.emit("login", { name: "Tom" })
off() // 取消订阅
```

```js
  }

Array.prototype.myReduce = function (fn, initial) {

    if (i in this) acc = fn(acc, this[i], i, this)
  }
  return acc
}
```

**题目 1：实现 `LazyMan`（链式延迟调用）**

```js
// LazyMan("Tom").eat("apple").sleep(2).eat("rice")
// 输出：Hi! I am Tom → eat apple → （等待 2 秒）→ eat rice
class LazyMan {
  constructor(name) {
    this.tasks = [() => console.log(`Hi! I am ${name}`)]
    setTimeout(() => this.run(), 0) // 等任务链构建完成再开始
  }
  eat(food) {
    this.tasks.push(() => console.log(`eat ${food}`))
    return this
  }
  sleep(sec) {
    this.tasks.push(
      () =>
        new Promise((r) =>
          setTimeout(() => {
            console.log(`sleep ${sec}s`)
            r()
          }, sec * 1000)
        )
    )
    return this
  }
  run() {
    this.tasks.reduce((p, task) => p.then(task), Promise.resolve())
  }
}
```

**题目 2：实现深比较（isEqual）**

```js
function isEqual(a, b) {
  if (a === b) return true
  if (typeof a !== typeof b) return false
  if (a === null || b === null || typeof a !== "object") return false
  // Date / RegExp
  if (a instanceof Date && b instanceof Date) return +a === +b
  if (a instanceof RegExp && b instanceof RegExp) return String(a) === String(b)
  // Map / Set
  if (a instanceof Map && b instanceof Map) {
    if (a.size !== b.size) return false
    for (const [k, v] of a) if (!isEqual(v, b.get(k))) return false
    return true
  }
  if (a instanceof Set && b instanceof Set) {
    if (a.size !== b.size) return false
    for (const v of a) if (!b.has(v)) return false
    return true
  }
  // 普通对象 / 数组：键集合 + 递归
  const keysA = Reflect.ownKeys(a)
  const keysB = Reflect.ownKeys(b)
  if (keysA.length !== keysB.length) return false
  return keysA.every((k) => isEqual(a[k], b[k]))
}
```
